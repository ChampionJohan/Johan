# 쇼피(Shopee) 크로스보더 셀링 사업 기획안

한국에서 상품을 사입해 쇼피(Shopee) 동남아 마켓에 파는 구조. 재고를 원격에서
관리할 수 있게 설계하면 디지털노마드 형태로 운영 가능하다.

## 1. 사업 모델 요약

```
국내 소싱 (동대문·다이소·제조사 직거래)
      ↓
포장·라벨링 (국내 위탁창고 또는 사입 대행)
      ↓
국제 배송 (Shopee 자체물류 SLS / 항공특송 / 해상 벌크)
      ↓
Shopee 마켓 판매 (SG·MY·TH·VN·PH·ID·TW 등)
      ↓
현지 통화 정산 → 원화 환전
```

핵심은 "한국산·K트렌드 프리미엄"이라는 정보 비대칭을 이용한 차익거래다.
직접 포장·발송을 하지 않아도 돌아가는 구조를 만드는 것이 원격 운영의 관건이다.

## 2. 진출 국가 우선순위

| 국가 | 장점 | 유의점 | 추천 순위 |
|---|---|---|---|
| 싱가포르 | 영어 기반, 결제·통관 안정적, 시장 검증용으로 적합 | 시장 규모 작음, 경쟁 심함(선진 소비자) | 1 (테스트 베드) |
| 말레이시아 | 한류 선호도 높음, 시장 안정적 | 무슬림 인증(할랄) 이슈 있는 카테고리 주의 | 2 |
| 베트남 | K-뷰티·K-패션 선호 강함, 성장률 높음 | 관세·통관 서류 요구 까다로움 | 2 |
| 태국 | K-콘텐츠 인기, 쇼피 라이브 활발 | 가격 민감도 높음, 경쟁 치열 | 3 |
| 필리핀 | 영어 통용, 진입장벽 낮음 | 물류 인프라 약함(배송 지연 잦음) | 3 |
| 대만 | 구매력 높음, 한국 상품 신뢰도 높음 | 시장 규모 작음 | 4 |
| 인도네시아 | 인구·시장 최대 | 할랄 인증, 현지어 필수, 통관 복잡 | 후순위(숙련 후) |

처음부터 여러 국가에 동시 진출하지 말고 1개국에서 판매·물류·CS 흐름을 검증한 뒤
확장하는 것을 권한다.

## 3. 취급 카테고리 후보

| 카테고리 | 예시 품목 | 장점 | 리스크 |
|---|---|---|---|
| K-뷰티 | 마스크팩, 선크림, 클렌징오일, 미니 스킨케어 세트 | 단가 낮고 반복구매율 높음 | 성분 규제(국가별 금지 성분 상이) |
| 패션 잡화 | 양말, 모자, 가방, 액세서리 | 부피 작고 파손 위험 낮음 | 사이즈·트렌드 재고 리스크 |
| 생활잡화 | 주방용품, 수납용품, 다이소류 | 국내 사입 단가 매우 낮음 | 단가가 낮아 마진 확보에 물량 필요 |
| 문구·캐릭터 굿즈 | 카카오프렌즈·라인프렌즈 등 | 마니아층 존재, 선물 수요 | 라이선스 정품 여부 확인 필수 |
| 건강기능식품 | 홍삼, 유산균, 비타민 | 단가 높아 마진 좋음 | 국가별 수입 금지 성분·인증 요건 있음, 사전 확인 필수 |
| K-pop 굿즈 | 포토카드, 앨범 | 팬덤 수요 확실 | 정품 유통 경로 확보 안 하면 위조품 리스크 |

**첫 아이템은 단가가 낮고, 규제가 없고, 파손 위험이 적은 카테고리(패션 잡화·생활잡화)로
시작해 물류·CS 프로세스를 먼저 익히는 것을 권한다.** 건강기능식품·화장품은 국가별
성분·인증 규제를 사전에 반드시 확인해야 한다.

## 4. 소싱 채널

- **동대문·남대문 도매시장**: 소량·다품종 테스트에 적합. 방문 없이 사입 대행업체를
  통해 원격으로 발주 가능.
- **다이소·생활용품점 대량구매**: 초저단가 상품 테스트용.
- **국내 도매 플랫폼**(오너클랜, 도매매 등): API 연동으로 재고·발주 자동화 가능,
  원격 운영에 유리.
- **제조사 직거래**: 물량이 커지면 단가 절감 폭이 가장 큼. 초기에는 비추천.

## 5. 쇼피 셀러 등록과 운영 구조

1. Shopee Seller Center에서 크로스보더 셀러 등록 (사업자등록증, 통장 사본, 대표자
   신분증 필요 — 최신 서류 요건은 등록 시점에 셀러센터에서 재확인할 것).
2. 국가별로 별도 스토어 개설이 필요한 경우가 많으므로, 진출 국가마다 등록 절차를
   따로 확인한다.
3. 상품 리스팅: 현지어 번역(자동번역 품질이 낮으면 클레임으로 이어지므로 핵심
   상품은 검수 필요), 사이즈·성분·원산지 표기.
4. 초기 리뷰 확보를 위해 소량 체험단·핫딜 참여를 활용한다.

## 6. 물류·통관

- **Shopee 자체 물류(SLS)**: 셀러가 국내에서 지정 발송처로 넘기면 이후 배송을
  쇼피가 처리하는 방식. 초기에는 직접 포장·발송 부담을 줄이는 데 유리.
- **항공특송 vs 해상 벌크**: 소량·빠른 테스트는 항공, 물량이 검증되면 해상 벌크로
  단가를 낮춘다.
- **통관**: 국가별 면세 한도, 필요 서류(원산지증명, 성분표 등)가 다르므로 카테고리
  확정 후 국가별로 개별 확인. 화장품·식품류는 인증 요건이 별도로 있는 경우가 많다.
- **반품 정책**: 역물류 비용이 순이익을 잠식하는 주요 원인이다. 파손 위험이 낮고
  사이즈 이슈가 없는 상품 위주로 시작해 반품률을 낮게 유지한다.

## 7. 가격·마진 설계 (예시 구조)

| 항목 | 비고 |
|---|---|
| 상품 원가 | 국내 사입가 |
| 국내 포장·배송비 | 위탁창고/사입대행 이용 시 대행 수수료 포함 |
| 국제 배송비 | SLS 또는 특송 단가 |
| 쇼피 카테고리 수수료 | 카테고리·국가별 상이, 등록 시점에 셀러센터에서 확인 |
| 결제·프로그램 수수료 | 크로스보더 프로그램 참여 시 별도 수수료 존재 |
| 광고비(CPC/쇼피 라이브) | 초기 노출 확보용, 매출 대비 %로 관리 |
| 환전 손실 | 현지통화 정산 → 원화 환전 시 스프레드 |

수수료·광고비를 모두 반영한 뒤 최소 20~30% 순마진이 남는 가격대인지 검증하고
리스팅해야 한다. 표의 정확한 수수료율은 변동이 잦으므로 실제 등록 시 셀러센터
공지를 기준으로 삼는다.

## 8. 마케팅

- **쇼피 라이브**: 동남아에서 라이브커머스 전환율이 높다. 초기엔 현지 파트너/
  대행사와 협업하는 방안도 검토.
- **쇼피 어필리에이트 프로그램**: 현지 인플루언서에게 수수료를 걸어 유입 확보.
- **플래시세일·쇼피 광고(CPC)**: 초기 노출 확보 수단. 예산을 정해두고 전환율
  기준으로 운영.
- **가격 경쟁력**: 동일 카테고리 상위 셀러 가격을 주기적으로 모니터링.

## 9. 디지털노마드형 원격 운영 설계

이 사업의 핵심 난제는 "재고가 한국에 있는데 사람은 해외에 있다"는 것이다.
아래 구조로 해결한다.

- **소싱·포장**: 국내 사입대행업체 또는 3PL(풀필먼트) 창고에 위탁 — 발주만
  원격으로 지시.
- **발송**: Shopee SLS 이용 시 국내 집하지까지만 넘기면 되므로 직접 발송 불필요.
- **CS**: 현지어 자동응답 템플릿 + 번역 툴, 시차를 고려한 응답 시간대 설정
  (예: 동남아는 한국과 시차 1~2시간이라 운영 부담이 크지 않음).
- **정산·세무**: 통신판매업 신고, 사업자등록, 해외판매 부가가치세·관세, 수출신고
  절차를 처음부터 세무사와 함께 세팅해둔다.
- **도구**: 재고관리·주문통합 툴(카페24, 셀러허브류의 멀티채널 관리 툴)로
  여러 국가 스토어를 한 대시보드에서 관리.

## 10. 리스크 체크리스트

- [ ] 통신판매업 신고 및 사업자등록 완료
- [ ] 수출신고 절차 확인(품목별 상이)
- [ ] 판매 예정 카테고리의 국가별 수입 금지/제한 성분 확인 (화장품, 건강기능식품)
- [ ] 캐릭터·브랜드 굿즈는 정품 유통 경로·라이선스 확인
- [ ] 반품·환불 정책과 역물류 비용 시뮬레이션
- [ ] 환율 변동 및 정산 주기(현지통화 → 원화) 확인
- [ ] 국가별 쇼피 셀러 등록 요건 최신본 확인 (정책 변경 잦음)

## 11. 실행 로드맵

| 기간 | 목표 |
|---|---|
| 1개월 차 | 시장·카테고리 조사, 쇼피 셀러 등록(1개국), 테스트 SKU 3~5개 소싱 |
| 2~3개월 차 | 첫 매출 발생, 리뷰 확보, 반품률·CS 대응 프로세스 안정화 |
| 4~6개월 차 | 검증된 SKU 확대, 2번째 국가 진출, 물류를 3PL/SLS로 전환해 원격 운영 완성 |
| 6개월 이후 | 베스트셀러 SKU의 물량 확대(해상 벌크 전환), 3~4개국 동시 운영 |

## 12. 다음 액션

1. 테스트 국가 1곳(싱가포르 또는 말레이시아 추천)과 카테고리 1~2개(패션 잡화·
   생활잡화)를 확정한다.
2. Shopee Seller Center에서 크로스보더 셀러 등록에 필요한 최신 서류 목록을
   확인한다.
3. 국내 사입대행업체 또는 3PL 후보 2~3곳을 비교 견적 받는다.
4. 세무사와 통신판매업 신고·수출신고 절차를 사전에 정리한다.
