# 헤세드 생태계 — 한 장 요약

난민과 선교사를 수혜자가 아니라 **오너**로 세운다 — 아이템을 주지 않고, 질문을 주고, 검증되면 자본을 붙인다.
시드 조당 RM 3,000 · 3회 분할 집행 · 현물 70% 이상 · 90일 1사이클 · 오너 5 : 투자자 5 · HTP 7중.

## 01 생태계 지도 — 4단계를 8슬롯으로

돈은 ① → ⑧ 을 한 바퀴 돌고 다시 ①로 간다. **슬롯이 잘게 쪼개질수록 자본 없는 사람이 들어갈 자리가 생긴다.**

```
                    ① 투입재
         ⑧ 소비자              ② 생산
                   ┌─────────┐
     ⑦ 마케팅·판매  │ 한 칸 위로│   ③ 1차가공
        (현 위치)   │ ⑦→⑥→③  │   (1기)
                   └─────────┘
       ⑥ 유통·도매             ④ 2차가공
          (1기)      ⑤ 물류·보관
```

| 슬롯 | 하는 일 | 1기 |
|---|---|:---:|
| ① 투입재 | 종자 · 사료 · 포장재 | |
| ② 생산 | 농장 · 양계 · 양어 | 2기부터 |
| ③ 1차가공 | 세척 · 선별 · 손질 | **●** |
| ④ 2차가공 | 제조 · 포장 · 브랜딩 | |
| ⑤ 물류 · 보관 | 배송 · 냉장 · 창고 | |
| ⑥ 유통 · 도매 | 식당 납품 · 소량 묶음 | **●** |
| ⑦ 마케팅 · 판매 | 노점 · 식당 · 배달 | **● 현 위치** |
| ⑧ 소비자 | 공동구매 · 단골 | |
| Ⓐ 자본 인프라 | 헤세드 펀드 — 이익의 10%, 무이자 회전 | |
| Ⓑ 신뢰 인프라 | 3줄 장부 · 교차감사 · 공개 대시보드 | |

**1기는 ⑥ ⑦ ③ 에서만 시작한다** — 자본 RM 1,000~3,000 · 검증 주기 7일 · 농장(②)은 2기부터.

## 02 돈의 구조 — 무엇을 5:5로 나누는가

| | 금액 (RM, 월) |
|---|---:|
| 매출 | 16,250 |
| − 매입원가 (원가율 76%) | 12,350 |
| − 운영비 (운송·포장·통신) | 700 |
| − 오너 인건비 (이익이 아니라 비용) | 1,000 |
| **= 영업이익** | **2,200** |
| − 투자원금 회수 30% (4.5개월 회수) | 660 |
| − 재투자 적립 10% | 220 |
| **= 분배가능이익** | **1,320** |
| → 오너 50% | 660 |
| → 투자자 50% | 660 |

각자 몫의 10%는 헤세드 펀드로 환원. 예시 A(식당 채소 납품) 기준.

## 03 지분 일몰 — 사업은 결국 오너의 것이 된다

| 연차 | 오너 | 투자자 |
|---|---:|---:|
| 1년차 | 50% | 50% |
| 2년차 | 50% | 50% |
| 3년차 | 60% | 40% |
| 4년차 | 70% | 30% |
| **5년차** | **100%** | **0%** |

투자자가 회수한 몫은 헤세드 펀드로 들어가 다음 기수의 시드가 된다.

## 04 헤세드 신뢰 프로토콜 — 감시가 아니라 구조

현물 70% 이상 · 2인 서명 · 24시간 영수증 · 3줄 장부 매일 · 월 교차감사 · 분기 외부검증 · 트랜치 40·30·30
