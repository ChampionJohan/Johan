# 부록 C · 투자합의서 체크리스트

> G3 통과 후, 자금 집행 **전에** 서명한다. 본 체크리스트는 계약서 초안용 점검표이며,
> 실제 계약서는 **현지 법률 검토를 거친 뒤** 현지어 번역본과 함께 각 1부씩 보관한다.

---

## 1. 당사자 · 구조

- [ ] 오너 성명, 신분증/UNHCR 카드 번호, 연락처, 비상 연락처
- [ ] 조 파트너 성명 및 역할 (영업 / 장부)
- [ ] 투자자 (헤세드 펀드 또는 개인 후원자) 명의
- [ ] 멘토(선교사) 성명 — 입회인 겸 승인권자
- [ ] **사업자 등록 명의자**와 그 법적 지위 (본문 10.1 A/B/C안 중 어느 구조인가)
- [ ] 명의자와 오너 사이의 **권리·의무 분리 조항** (명의자는 수익권 없음을 명시)

## 2. 금액 · 집행

- [ ] 총 투자금액 및 통화
- [ ] 트랜치 분할표: T1 40% / T2 30% / T3 30%
- [ ] 각 트랜치의 **집행 조건(게이트)** 명시
- [ ] **현물 지급 비율 70% 이상** 조항
- [ ] 공동명의 계좌 정보 및 **2인 서명 기준액(RM 500)**
- [ ] 집행되지 않은 잔여 트랜치의 소멸 조건

## 3. 이익 분배

- [ ] 영업이익 정의 (매출 − 매입원가 − 운영비 − 오너 인건비)
- [ ] **오너 인건비 월 고정액** 명시
- [ ] 원금회수 30% / 재투자 적립 10% 조항
- [ ] 분배가능이익 **오너 50 : 투자자 50**
- [ ] 각자 몫의 10% **헤세드 펀드 환원**
- [ ] **지분 일몰표** (3년차 40% → 4년차 30% → 5년차 0%)
- [ ] 정산 주기 (월 1회 권장) 및 정산일

## 4. 투명성 의무 (HTP)

- [ ] 3줄 장부 매일 기록 및 공개
- [ ] 지출 24시간 내 영수증 촬영·업로드, **미제출 지출 개인 부담** 조항
- [ ] 월 1회 교차감사 수용 의무
- [ ] 분기 외부검증 수용 의무
- [ ] 대시보드 공개 항목 동의

## 5. 실패 · 부정

- [ ] **정직한 실패 시 상환 의무 없음** (지분 투자이지 대출이 아님을 명시)
- [ ] 실패 보고서 1페이지 제출 의무
- [ ] 부정 3단계 조치 (경고 / 6개월 자격정지 / 퇴출)
- [ ] **부정 적발 시 투자금 전액이 개인 채무로 전환**된다는 조항
- [ ] 장부 부재 = 2단계 부정 간주 조항
- [ ] 회복 경로 (상환 50% → 참관 / 100% + 보증 2인 → 재심)

## 6. 종료 · 분쟁

- [ ] 계약 기간 및 갱신 조건
- [ ] 오너의 자진 중단 시 절차 (재고·자산 정산 방법)
- [ ] 오너의 이주·강제 이송 등 불가항력 발생 시 처리
- [ ] 분쟁 해결 절차: ① 멘토 조정 → ② 오너 3인 합의체 → ③ 현지 법적 절차
- [ ] 준거 지역 및 언어 (분쟁 시 **현지어 번역본을 정본**으로 할지 명시)

## 7. 서명

- [ ] 오너 서명 / 날짜
- [ ] 파트너 서명 / 날짜
- [ ] 투자자 서명 / 날짜
- [ ] 멘토(입회인) 서명 / 날짜
- [ ] 각 당사자 1부씩 보관 + 사진본 공용 보관
- [ ] **현지어 번역본 첨부 및 낭독 확인** — 읽어주지 않은 계약서는 계약이 아니다

---

> 서명 전 반드시 소리 내어 읽는다. 특히 **5. 실패 · 부정** 항목은 한 줄씩 확인한다.
> "실패는 벌하지 않는다. 숨김을 벌한다" — 이 문장을 계약서 첫 줄에 넣을 것을 권한다.
