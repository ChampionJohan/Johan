# 용돈 기입장

오늘 쓴 돈을 입력하면 자동으로 이번 달 지출을 정리해주는 단일 HTML 앱. 의존성 없음, 서버 없음 — 브라우저에서 파일만 열면 동작한다.

## 사용법

```
open allowance-ledger/index.html   # 또는 브라우저에서 파일 직접 열기
```

1. 날짜 · 분류 · 금액 · 메모를 입력하고 "기록 추가"
2. 이번 달 총 지출, 분류별 지출 비중이 자동으로 갱신됨
3. "월별 비교" 카드에서 최근 6개월간 기록과 이번 달을 비교
4. 상단의 월 선택 드롭다운으로 지난 달 기록도 조회 가능
5. "마크다운으로 내보내기"로 이번 달 리포트를 `.md` 파일로 저장, "인쇄/HTML 저장"으로 인쇄하거나 PDF로 저장

## 데이터 저장

모든 기록은 브라우저의 `localStorage`에만 저장되며 외부로 전송되지 않는다. 기기를 옮기거나 백업하려면 마크다운 내보내기 기능을 사용한다.

## 비교 로직

- **전월 대비**: 이번 달 총액을 바로 이전 달 총액과 비교해 증감액·증감률을 표시
- **월별 비교**: 기록이 있는 최근 6개월의 총 지출을 막대그래프로 나란히 비교
