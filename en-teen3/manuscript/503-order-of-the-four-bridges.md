## You can't build four at once

Chapter 2 named the four bridges.
Part Three looked at them one at a time.

**Repeat · Shape · Patina · Handoff.**

| Bridge | What it asks |
|---|---|
| **Repeat** | is there a reason to buy again? |
| **Shape** | recognized with the name covered? |
| **Patina** | better with use? |
| **Handoff** | can it pass to someone else? |

One question left.

**Which one first?**

You can't build four at once. Not enough money or time.
So there has to be an order, **and the order isn't arbitrary.**

## The usual thought — start with the impressive one

**Half right.**

The impressive one is usually **Shape.** The one people recognize on sight.
So everyone starts there.

Start with Shape and this happens a lot:

**People recognize it and there's no reason to buy again.**

You make one good-looking thing and it's over.
That's exactly where Part Two starts.

The order has to be **the reverse of the order things collapse in,
not the order of impressiveness.**

## The order

**First, Repeat.**

Simple reason:

> **Without Repeat there's no time to build the other three.**

Shape takes time to become known.
Patina literally requires time to pass.
Handoff requires being around long enough for someone to hand it to.

**All three eat time, and Repeat is what buys that time.**

Chapter 9 said "the time coming round" is the strongest kind. That pays off here.

**Second, Shape.**

Once there's Repeat, the next job is **not being confusing.**

If they come back to buy and don't know which one to buy,
Repeat doesn't accumulate. Shape solves that.

And Shape has the good property from Chapter 8.
**It's maintained with no monthly payment.**

**Third, Patina.**

From here it takes time. It can't be pulled forward.

So it's third, **and it has to be designed on day one.**
Build it without long use in mind and you can't add it later.

**Fourth, Handoff.**

The slowest. Enough has to pile up to be worth passing on.

**Its conditions also have to be built in advance.**
It has to be made so it *can* pass to someone, or it never will.

So:

> **Build order: Repeat → Shape → Patina → Handoff.
> Design order: all four on day one.**

## When to build — before it takes off

The most important sentence in the chapter.

Build after it takes off and it costs more for three reasons.

**One. People have already decided what the thing is.**
Change it later and it becomes a different thing.

**Two. When it's going well you can't make a decision that reduces anything.**

That's the real reason. More on it below.

**Three. Big things can't change.**
The more that's fixed, the more changing costs.

So Chapters 14 and 15 **have to happen together.**
Think about landing after you've taken off and it's already late.

## Why nobody does it

The part of this book that has to be most honest.

All four bridges **reduce what you earn right now.**

Repeat means not selling big once.
Shape means not changing with fashion.
Patina means long use and fewer sales.
Handoff means the person who inherited it doesn't buy one.

**Judged by this month, not building is always correct.**

> **Bridges aren't expensive.
> The decision is hard because they reduce what you earn now.**

That sentence is the line between Part Two and Part Three.

The things that vanished didn't vanish from lack of money.
**They vanished because this month was correct every time.**

And it's the only genuinely hard thing in this book.
The rest is just knowing.

## If you can't build all four

Something realistic.

Building all four is hard. Most don't.

**Two is enough to last a long time.**

The character changes with the combination.

| The two built | What you get |
|---|---|
| Repeat + Shape | **steady sales.** The safest |
| Repeat + Patina | users rarely leave |
| Shape + Handoff | talked about for a long time. Money comes slowly |
| Patina + Handoff | **the object survives.** The slowest |

**One bridge is precarious.** If that one wobbles it's over.

So the target isn't four. **It's two.**

## Check yourself

Four lines, yes or no.

**One.** Does someone who liked this have **a reason to buy again?** (Repeat)

**Two.** Cover the name — **is it recognizable?** (Shape)

**Three.** Is a year-old one **better than a new one?** (Patina)

**Four.** Can you **hand this to someone and have it still work?** (Handoff)

Zero yeses means no bridges yet.
Then however well it's going, **you're standing on the Part Two side.**

One yes means building a second one is this year's work.

Two or more is genuinely solid.
**And not letting go of those two is the whole of the work ahead.**

## The short version

| Question | Answer |
|---|---|
| The order | **Repeat → Shape → Patina → Handoff** |
| Why Repeat first | **it buys the time to build the other three** |
| When to build | **before takeoff.** Together with Chapter 14 |
| Why nobody does | all four **reduce what you earn now** |
| Part Two vs Part Three | **whether this month won every time** |
| How many needed | **two is solid** |

## Do This Today

Answer the four lines above about something you're making.

Yes or no only. Don't write essays.

Then **pick one of the noes.**

If you can't decide which, **pick Repeat.** That's the order.

Then write one last line.

> **If I build this bridge, what goes down?**

If you can write that line, you've read this book properly.

**If nothing goes down, it isn't a bridge.**
There is no bridge in the world you can build while giving up nothing.
