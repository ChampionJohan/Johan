# 웹사이트 + GitHub Pages + 애드센스로 월 30만 원 만들기 (처음부터)

> 작성일 2026-10-05 · 대상: 코딩 비전문가 · 도구: GitHub, Claude Code, Google AdSense

## 0. 결론 먼저

- **가능합니다. 다만 "만들면 바로 수익"이 아닙니다.** 월 30만 원은 보통 **글/도구 50~100개 + 6~12개월** 뒤에 도달하는 목표입니다. 3개월 안에 달성하는 경우는 드뭅니다.
- **필요 트래픽:** 월 **약 6만 ~ 15만 페이지뷰(PV)**. (아래 계산 참고)
- **GitHub Pages는 무료 호스팅으로 충분하지만, 도메인(연 1~2만 원)은 사세요.** `아이디.github.io` 주소로는 애드센스 승인·`ads.txt` 설정이 불리하거나 막힐 수 있습니다.
- **성공 여부의 80%는 "주제 선택 + 글 품질 + 꾸준함"** 이지, 사이트 기술이 아닙니다.

## 1. 월 30만 원에 필요한 방문자 계산

> 아래 RPM(1,000 PV당 수익)은 **업계에서 흔히 거론되는 대략적 범위(추정)** 이며, 주제·계절·광고 배치에 따라 크게 달라집니다. 환율 약 1,400원/달러 가정.

| 시나리오 | 페이지 RPM(원) | 필요 월 PV | 하루 PV |
|---|---|---|---|
| 보수적 | 2,000 | 150,000 | 약 5,000 |
| 보통 | 3,500 | 약 86,000 | 약 2,900 |
| 낙관적 | 5,000 | 60,000 | 약 2,000 |

- 수식: `필요 PV = 300,000원 ÷ RPM × 1,000`
- 한 방문자가 평균 1.5페이지를 본다면, **하루 순방문자 1,500~3,000명** 수준입니다.
- 애드센스 수익의 **68%** 가 게시자에게 지급됩니다(위 RPM은 지급액 기준으로 보세요).

## 3. 1단계: 주제(니치) 고르기 — 가장 중요

**원칙 3가지**

1. **검색해서 찾아오는 주제** (SNS 바이럴이 아니라 구글·네이버 검색 유입)
2. **계속 새 글을 쓸 수 있는 주제** (최소 100개 글감)
3. **본인이 실제 경험·전문성이 있는 주제** (구글이 경험 기반 콘텐츠를 선호)

**조한 님 프로필에 맞는 후보**

| 후보 | 장점 | 주의 |
|---|---|---|
| 공공 IT 사업관리 양식·가이드 (회의록, 산출물, 검수, 제안서 템플릿) | 15년 경력 활용, 경쟁 적음, 검색 의도 명확 | 시장이 작아 PV 천장이 낮을 수 있음 |
| 업무용 AI 활용법 (ChatGPT/Claude로 보고서·메일 쓰기) | 수요 큼, 목표(AI 전파자)와 일치 | 경쟁 치열, 빠른 최신화 필요 |
| **계산기/변환 도구 사이트** (예: 근무일수 계산, 연차 계산, 퇴직금 계산) | 재방문·체류 높음, 한 번 만들면 오래감 | 정확성 책임, 법령 변경 반영 |
| 말레이시아·필리핀·태국 생활/여행/이주 정보(한국어) | 현지 경험이 차별점 | 사진·현장 정보 직접 수집 필요 |

**추천 조합:** `업무용 AI + 사업관리 템플릿 + 간단 계산기 도구` 를 한 사이트에서 묶는 방식. 템플릿/도구는 검색 유입이 꾸준하고, 글은 신뢰를 쌓습니다.

**하지 말 것:** AI가 쓴 글을 검수 없이 대량 게시. 구글은 대량 생성·저품질 콘텐츠를 낮게 평가하며, 애드센스 "가치가 별로 없는 콘텐츠" 사유 거절의 주된 원인입니다.

## 4. 2단계: 도메인 + GitHub Pages로 사이트 공개

### 4-1. 준비물

| 항목 | 비용 | 비고 |
|---|---|---|
| GitHub 계정 | 무료 | 이미 있음 (`championjohan`) |
| GitHub Pages | 무료 | 공개 저장소 기준 |
| 도메인 (.com 등) | 연 약 1~2만 원 | 가비아, Cloudflare Registrar, Namecheap 등 |
| Google 계정 / AdSense | 무료 | 만 18세 이상, 본인 명의 |

### 4-2. 배포 절차

1. GitHub에서 저장소 생성 (예: `my-site`), Public.
2. 사이트 파일 업로드 (루트에 `index.html`). **Claude Code에게 "이 주제로 정적 사이트 만들어줘"** 라고 시키면 HTML/CSS/글 템플릿까지 만들어 줍니다.
3. 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 선택, Save.
4. 1~3분 뒤 `https://아이디.github.io/my-site/` 에서 확인.
5. **커스텀 도메인 연결**
   - Settings → Pages → Custom domain 에 `example.com` 입력.
   - 도메인 DNS에 A 레코드 4개(GitHub Pages IP: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) + `www` CNAME(`아이디.github.io`) 설정. *(IP는 변경될 수 있으니 공식 문서에서 재확인)*
   - **Enforce HTTPS** 체크.
6. 저장소 루트에 `CNAME` 파일(내용: `example.com`)이 생겼는지 확인.

공식 문서: <https://docs.github.com/pages>

### 4-3. 사이트 구조 권장

```
/                  홈 (최신글 + 카테고리)
/posts/            글 목록
/tools/            계산기·도구
/about/            소개 (운영자 실명·경력 — 신뢰 신호)
/privacy/          개인정보처리방침 (애드센스 필수)
/contact/          문의 (이메일)
/ads.txt           애드센스 승인 후 추가
/sitemap.xml       검색엔진용
/robots.txt
```

## 5. 3단계: 승인받기 위한 콘텐츠 기준

애드센스 승인에 **공식 글 수 기준은 없지만**, 실무적으로 아래를 갖추면 통과 확률이 높아집니다(경험칙, 보장 아님).

- **독창적인 글 25~30편 이상**, 각 1,500자 이상, 실제 경험·수치·스크린샷 포함
- 소개/문의/개인정보처리방침 페이지 완비
- 모바일에서 잘 보이는 반응형 디자인, 깨진 링크 없음
- 타인 글 복사·번역 도배 금지, 저작권 이미지 금지
- 메뉴 이동이 쉬운 구조, 사이트가 "완성된 서비스"로 보일 것

**글 1편 체크리스트**

1. 검색 의도(질문) 1개에 정확히 답하는가
2. 제목에 핵심 키워드 포함, 소제목(H2/H3)으로 구조화
3. 내 경험·실제 숫자·직접 캡처가 들어갔는가
4. 읽고 나서 "다른 글 안 봐도 된다"는 느낌이 드는가

## 6. 4단계: 애드센스 신청 → 승인 → 광고 넣기

1. <https://adsense.google.com> 접속 → 사이트 URL(커스텀 도메인) 입력 → 결제 국가 대한민국.
2. 안내된 **AdSense 코드 스니펫**을 모든 페이지 `<head>` 에 삽입(Claude에게 공통 템플릿에 넣도록 요청).
3. 사이트 소유권 확인 후 검토 요청. 보통 **며칠~4주**.
4. 승인되면 `ads.txt` 에 안내된 한 줄(`google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`)을 저장소 루트에 추가.
5. **자동 광고(Auto ads)** 로 시작 → 데이터가 쌓이면 본문 중간·제목 아래 등 수동 배치 보강.
6. 정책 준수: **내 광고 클릭 절대 금지**, 클릭 유도 문구 금지. 계정 영구 정지 사유입니다.

**거절 사유와 대처**

| 거절 사유 | 대처 |
|---|---|
| 가치가 별로 없는 콘텐츠 | 글 수·분량·독창성 보강 후 2~4주 뒤 재신청 |
| 사이트 탐색이 어려움 | 메뉴/카테고리/내부 링크 정리 |
| 정책 위반 콘텐츠 | 해당 글 삭제·수정 |

공식 도움말: <https://support.google.com/adsense>

## 7. 5단계: 트래픽 늘리기 (6~12개월의 본게임)

| 방법 | 내용 | 비용 |
|---|---|---|
| **Google Search Console** 등록 | 사이트맵 제출, 색인 요청, 검색어 확인 | 무료 |
| **네이버 서치어드바이저** 등록 | 국내 검색 유입(한국어 사이트 필수) | 무료 |
| 롱테일 키워드 | "회의록 양식 공공기관" 처럼 구체적 검색어 공략 | 무료 |
| 인기 글 갱신 | 상위 노출 글 분기마다 최신화 | 시간 |
| 내부 링크 | 관련 글끼리 연결해 체류·PV 증가 | 시간 |
| 도구/템플릿 다운로드 | 재방문·백링크 유도 | 시간 |

**현실적인 작성 속도:** 주 3~5편 × 6개월 ≈ 80~120편. 그중 상위 10~20%가 트래픽 대부분을 만듭니다.

## 9. 수익·세금·지급

- **지급 기준:** 누적 수익이 일정 금액(한국 기준 보통 약 $100 상당)을 넘으면 지급. 기준 금액은 AdSense 계정의 "지급" 메뉴에서 확인.
- **PIN 우편 인증**(수익 약 $10 도달 시)과 은행 계좌 등록 필요.
- **세금:** 애드센스 수익은 한국에서 사업소득으로 분류되는 것이 일반적이며, 매년 5월 **종합소득세 신고** 대상입니다. 지속적 수익이면 **사업자등록** 필요 여부는 관할 세무서·세무사 확인. 회사 겸업 규정(소프트아이텍 취업규칙)도 **사전 확인** 하세요.
- Google의 미국 세금 정보(W-8BEN) 입력 필요.

## 10. 위험과 한계 (객관적으로)

1. **수익은 보장되지 않습니다.** 대다수 신규 사이트는 월 수만 원 이하에서 정체합니다.
2. **검색 알고리즘 변화**(AI 요약 검색 확대 등)로 클릭이 줄어드는 추세가 있어, 단순 정보형 글은 불리합니다. **도구·템플릿·직접 경험형** 콘텐츠가 상대적으로 안전합니다.
3. 애드센스 정책 위반 시 **계정 정지** 가능. 광고 의존도를 낮추려면 장기적으로 제휴 링크·전자책·템플릿 판매를 병행.
4. 초반 3~6개월은 **수익 0원 구간** 입니다. 투자 시간은 주 8~10시간 이상으로 잡으세요.
