# 영상 대본 규칙과 자료 사용 원칙

`writing/STYLE.md` 가 글에 대한 규칙이라면, 이 파일은 영상에 대한 규칙이다.
사람과 자동 스캐폴딩이 함께 지킨다.

## 1. 대본 규칙

**말로 읽을 문장만 쓴다.** 눈으로 읽으면 되지만 입으로 읽으면 걸리는 문장은 전부 다시 쓴다.

- 한 문장 40자 이내. 접속사로 이어 붙이지 말고 끊는다.
- 숫자는 소리 나는 대로. "$3.2B" 가 아니라 "3조 2천억 원 정도".
- 한자어 대신 입말. "당해 매출액이 감소하였다" → "그해 매출이 줄었다".
- 괄호를 쓰지 않는다. 괄호가 필요하면 문장을 나누거나 화면 자막으로 뺀다.
- 지시어("이것", "그것")를 연속으로 쓰지 않는다. 화면을 안 보는 시청자가 절반이다.

**첫 문장에 반드시 숫자나 반전이 있어야 한다.** "오늘은 스포티파이에 대해 알아보겠습니다" 로 시작하는 대본은 폐기.

**일반론이 나오면 그 문단은 죽은 것이다.** "혁신이 중요합니다" 대신 "2013년에 매출 절반을 포기했습니다".

## 2. 매 편 지켜야 할 것

- BM 5칸(고객·가치·과금·해자·균열)을 전부 채운다. 한 칸이라도 비면 발행하지 않는다.
- 숫자에는 **연도와 출처**가 붙는다. 대본 맨 아래 출처 목록과 1:1로 맞는다.
- 확인 못 한 숫자는 쓰지 않는다. "알려져 있습니다" 는 출처가 아니다.
- 마지막 40초는 항상 "한국에 옮기면" 으로 끝난다. 시청자가 남의 나라 얘기로 안 느끼게 하는 유일한 장치.
- 다음 편 제목을 예고한다. 예고한 편은 반드시 그 순서로 낸다.

## 3. 자료 활용 — 무엇을 써도 되나

### 사실과 숫자 (마음껏 쓴다, 출처만 밝힌다)

사실 자체에는 저작권이 없다. 표현을 베끼지 않고 숫자와 사실만 가져오면 된다.

| 종류 | 어디서 |
|---|---|
| 기업 실적 | 각 사 IR 페이지, 미국 상장사는 SEC EDGAR 의 10-K / 20-F |
| 국가·산업 통계 | World Bank, OECD, IMF, 각국 통계청, 한국은행 ECOS |
| 농업·어업 | FAO(유엔식량농업기구) FishStat / FAOSTAT, 해양수산부 |
| 관광·숙박 | UNWTO, 각국 관광청 연차보고서 |
| 스포츠 | 리그 공식 재무공시, Deloitte Football Money League |
| 국내 기업 | DART 전자공시 |

**규칙: 1차 출처 3개 이상.** 다른 유튜브 영상이나 블로그는 출처가 아니라 단서다. 거기서 본 숫자는 원 자료로 다시 확인한다.

### 화면에 쓸 영상·이미지 (여기서 채널이 죽고 산다)

**쓰면 안 되는 것**: 방송 클립, 영화·드라마 장면, 남의 유튜브 영상, 검색해서 나온 사진.
짧게 잘라 써도 안 된다. 수익 창출 거절과 저작권 경고의 대부분이 여기서 나온다.

**써도 되는 것**:

| 종류 | 출처 | 주의 |
|---|---|---|
| 무료 스톡 영상 | Pexels, Pixabay, Videvo, Coverr | 라이선스 페이지를 한 번은 읽을 것 |
| 유료 스톡 | Artgrid, Storyblocks, Envato Elements | 월 3~5만 원. 8편 넘어가면 본전 |
| 사진·도표 | Wikimedia Commons | CC-BY 는 **화면 안에 저작자 표기 필수** |
| 정부·기관 자료 | 각국 정부 공개자료, 공공누리 제1유형 | 유형 번호 확인 |
| 기업 이미지 | 각 사 프레스킷 / 미디어 페이지 | 보도용 허용 범위 안에서 |
| 음악 | YouTube 오디오 보관함, Epidemic Sound, Artlist | 오디오 보관함은 무료·무표기 |
| 폰트 | Pretendard, 나눔, 지마켓 산스 | 상업적 이용 가능 여부 재확인 |

**가장 안전하고 가장 강한 소재는 직접 만든 그래픽이다.** 수익 구조 다이어그램, 매출 추이 막대,
BM 5칸 표 — 이건 저작권 문제가 없고 채널 정체성이 되며 재사용도 된다.
화면의 절반 이상을 자체 제작으로 채우는 걸 목표로 한다.

### 공정이용에 기대지 말 것

한국 저작권법 제35조의5(공정이용)는 **소송에서 쓰는 방어 논리**지 사용 허가가 아니다.
유튜브의 판단은 그보다 먼저 온다. 인용이 꼭 필요하면 세 가지를 전부 지킨다:
분량은 최소로, 목적은 비평·설명, 출처는 화면에 표기. 그래도 안전하지는 않다.

### 재사용 콘텐츠 정책

스톡 푸티지 + TTS 나레이션 조합은 유튜브 수익 창출 심사에서 **재사용 콘텐츠**로 걸리기 쉽다.
피하는 방법은 세 가지뿐이다.

1. 자체 제작 그래픽 비중을 높인다 (위 참고)
2. 본인 목소리로 녹음한다 — TTS보다 심사에도, 신뢰도에도 유리하다
3. 해설·분석·의견이 실제로 들어간다 — 사실 나열만 있으면 재사용으로 본다

## 4. 제목·썸네일

- 제목은 회사/국가 이름 + 상식을 깨는 사실. 40자 이내.
- 물음표로 끝나는 제목은 편당 하나 이하. 남발하면 낚시 채널이 된다.
- 썸네일 글자는 **4단어 이하**, 휴대폰 크기로 줄여도 읽히는지 반드시 확인.
- 카테고리 색을 고정한다 (IT 파랑 / 금융 초록 / 음식 주황 …). 목록에서 시리즈로 보인다.

## 5. 발행 전 점검

- [ ] 모든 숫자에 연도와 출처가 붙었나
- [ ] 1차 출처 3개 이상인가
- [ ] 화면에 쓴 소재 중 라이선스 확인 안 된 게 있나
- [ ] 첫 문장에 숫자나 반전이 있나
- [ ] 7:30~8:00 에 가장 뜻밖의 사실이 있나
- [ ] 마지막 40초가 "한국에 옮기면" 으로 끝나나
- [ ] 다음 편 예고가 큐의 다음 항목과 같나
- [ ] 나레이션 3,000~3,400자 범위인가
