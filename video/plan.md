# 세계의 비즈니스 모델 — 시리즈 기획과 편성 큐

주 1회, 10분 영상. 세계 각지의 사업이 **정확히 어디서 돈을 버는지** 구조로 해부한다.
`tools/new_video.py` 가 이 파일을 읽는다. **여기만 고치면 다음에 만들 영상이 바뀐다.**

## 0. 한 줄 정의

> "저 회사는 대체 뭘 팔아서 돈을 벌까?" 를 10분 만에 구조로 보여 주는 채널.

시청자는 사업을 하거나 하려는 사람, 취준생·직장인 중 산업 구조가 궁금한 사람.
경쟁 채널과의 차이는 **매 편 같은 5칸 틀로 해부한다는 것** — 낱개 지식이 아니라 비교 가능한 데이터가 쌓인다.

## 1. BM 5칸 — 시리즈의 뼈대

매 편 이 다섯 칸을 채운다. 영상 안에 고정 그래픽으로 넣고, 채널의 정체성이 된다.

| 칸 | 질문 | 영상 내 위치 |
|---|---|---|
| 1. 고객 | 실제로 **돈을 내는 사람**은 누구인가 (쓰는 사람과 다를 수 있다) | 2:30~ |
| 2. 가치 | 그 사람은 무엇에 돈을 내는가 | 3:20~ |
| 3. 과금 | 어떻게 받는가 — 구독·수수료·광고·마진·리스·프랜차이즈·라이선스 | 4:10~ |
| 4. 해자 | 왜 남이 못 뺏는가 | 5:30~ |
| 5. 균열 | 어디서 무너지는가 | 7:30~ |

**한 편에 회사 하나, 5칸 한 세트.** 두 회사를 비교하고 싶으면 그건 다음 편이다.

## 2. 카테고리 로테이션

9개 카테고리를 이 순서로 돈다. 한 바퀴 9주, 1년이면 약 5.8바퀴.
대중적인 주제(IT·음식·금융)를 사이클 앞쪽에 둬서 매 바퀴 유입을 만든다.

`IT → 음식 → 금융 → 숙박 → 마케팅 → 스포츠 → 경제 → 농업 → 어업`

**경제 카테고리 정의**: 나머지 8개와 층위가 달라 그대로 두면 잡탕이 된다.
이 채널에서 "경제"는 **국가·도시를 하나의 사업체로 보고 해부하는 편**으로 좁힌다.
(예: 싱가포르는 무엇을 팔아서 먹고사는가)

## 3. 포맷 규격

| 항목 | 롱폼 | 숏폼 |
|---|---|---|
| 길이 | 9분 30초 ~ 10분 30초 | 45~60초 |
| 나레이션 분량 | 3,000~3,400자 (공백 포함, 분당 약 330자) | 250~330자 |
| 발행 | 주 1회, 같은 요일 같은 시각 | 주 2~3회 (롱폼 부산물) |
| 화면 | 자체 제작 그래픽 50% 이상 + 스톡 B롤 | 세로 9:16, 자막 필수 |

### 롱폼 10분 타임코드 (매 편 동일)

```
0:00 - 0:20   훅        숫자 한 줄. "이 회사는 커피를 팔지 않습니다."
0:20 - 0:50   질문      오늘 풀 질문 + 채널 소개 5초
0:50 - 2:30   배경      이 시장이 어떻게 생겼는지, 상식 한 겹
2:30 - 5:30   해부      BM 5칸 중 1·2·3 (고객 / 가치 / 과금)
5:30 - 7:30   해자      4번 칸. 왜 안 뺏기는가
7:30 - 9:00   균열      5번 칸. 리스크와 한계
9:00 - 9:40   적용      한국에 옮기면 어떻게 되는가 (시청자와 연결되는 지점)
9:40 - 10:00  마무리    한 줄 요약 + 다음 편 예고 + 구독
```

8:00 지점에 시청 이탈이 몰린다. **가장 뜻밖의 사실 하나를 7:30~8:00 에 배치할 것.**

## 4. 시작 단계 — 숏폼 먼저, 롱폼 나중

바로 10분을 만들면 4편쯤에서 지친다. 3단계로 올린다.

| 단계 | 기간 | 만드는 것 | 목적 |
|---|---|---|---|
| 1단계 | 1~4주차 | 60초 숏폼 주 3편 (총 12편) | 훅 감각, 편집 속도, 목소리 톤 확정 |
| 2단계 | 5~8주차 | 3분 미드폼 주 1편 + 숏폼 주 2편 | 5칸 중 3칸만 다루며 구성 연습 |
| 3단계 | 9주차~ | 10분 롱폼 주 1편 + 숏폼 주 2~3편 | 본 궤도 |

1·2단계에서 쓰는 주제는 아래 큐의 앞쪽 편들을 미리 잘라 쓴다.
**리서치는 한 번, 결과물은 세 개** — 롱폼 하나에서 숏폼 3개가 나온다 (훅 / 뜻밖의 사실 / 5번 칸 균열).

## 6. 무엇을 자동화하고 무엇을 안 하나

| 단계 | 누가 |
|---|---|
| 편성 큐에서 다음 편 꺼내기 | 자동 (매주 월 09:00) |
| 대본 뼈대 · 타임코드 · 5칸 표 · 업로드 항목 | 자동 |
| 썸네일 · 5칸 그래픽 · 구간 카드 SVG | 자동 (`video_assets.py`) |
| 그 주 할 일 체크리스트 | 자동 (GitHub 이슈) |
| **리서치 · 숫자 · 출처** | **사람** |
| **대본 문장** | **사람** |
| 나레이션 · 편집 | 사람 |
| 나레이션 텍스트 · 설명란 · 챕터 · 태그 조립 | 자동 (`video_export.py`) |
| 업로드 | 사람 (스튜디오 예약 발행 권장) |

리서치를 자동화하지 않는 이유는 이 저장소의 원칙과 같다. 실존 기업의 숫자를 다루는 채널에서
틀린 숫자 하나는 되돌릴 수 없고, 5칸 중 한 칸이라도 근거 없이 채워지면 시리즈 전체가 무너진다.

## 7. 주간 제작 리듬

주당 9~11시간. 처음 4편은 15시간쯤 걸린다.

| 요일 | 할 일 | 시간 |
|---|---|---|
| 월 | 리서치. 1차 출처 5개 이상 확보, 숫자 확정 | 2h |
| 화 | 대본 3,200자. TODO 없이 끝까지 | 2h |
| 수 | 나레이션 녹음 + 자막 초안 | 1h |
| 목 | 편집. 자체 그래픽 먼저, B롤은 빈칸 메우기 | 3h |
| 금 | 썸네일 3안 + 제목 5안 → 예약 업로드 | 1h |
| 토 | 같은 대본에서 숏폼 3편 잘라내기 | 1.5h |

**한 주 밀리면 재고에서 꺼내 쓴다.** 항상 완성본 2편을 앞서 만들어 두는 게 목표.

## 8. 무엇을 보고 판단하나

12편(약 3개월)까지는 조회수를 보지 말고 발행 리듬만 지킨다. 그 뒤에 볼 지표:

| 지표 | 기준선 | 밑돌면 고칠 곳 |
|---|---|---|
| 클릭률(CTR) | 4% 이상 | 썸네일과 제목 |
| 평균 시청 지속 시간 | 4분 이상 (10분 영상) | 구성. 특히 2~4분 구간 |
| 첫 30초 이탈률 | 40% 미만 | 훅. 첫 문장에 숫자가 없는지 |
| 숏폼 → 채널 유입 | 조회수 대비 1% | 숏폼 끝의 유도 문구 |

- **머니 머신** — 짧고 검색이 겹침. 비추천
- **돈이 흐르는 구조** — 채널 정체성과 정확히 일치
- **비즈니스 해부실** — 5칸 틀과 잘 붙음
- **월드 비즈니스 코드** — 확장성 좋음
