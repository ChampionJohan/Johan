# 투자쇼츠 만들기 (복사해서 붙여넣기만 하면 됩니다)

## 사용법 3단계
1. 아래 [A] 블록을 복사하고, 맨 위 줄의 유튜브 링크만 바꿔서 Claude에게 보냅니다.
2. Claude가 돌려준 [B] 블록을 그대로 Mirra 입력창에 붙여넣습니다.
3. 영상을 내려받은 뒤 [C] 블록을 유튜브 업로드 화면에 붙여넣습니다.

---

## [A] Claude에게 보낼 요청문 (다음부터 이것만 쓰세요)

```
투자쇼츠 만들어 줘: (여기에 유튜브 링크)

조건:
- 60초 세로 쇼츠, 사람은 나오지 않고 설명만 (모션그래픽과 이미지)
- 한국어 내레이션, 한국어 자막
- 원본 유튜버는 언급하지 말고 "이렇게 하면 된다" 방법 설명 형식으로
- 영상에 나온 도구 이름(예: 클로드)은 짧게 언급
- Mirra(mirra.my)에 한 번에 붙여넣을 수 있는 입력문 1개
- 유튜브 제목, 설명란, 해시태그를 한 번에 붙여넣을 수 있는 블록 1개
- 확인 안 된 숫자는 지어내지 말고 표시해 줘
- 원본 영상은 직접 쓰지 말고, 출처만 설명란에 적어 줘
```

---

## [B] Mirra 입력문 (이번 영상용)

```
유튜브 쇼츠용 60초 세로(9:16) 영상을 만들어 줘.
출연자 없이 모션그래픽과 이미지로만 구성.
한국어 내레이션(차분한 아나운서 톤)과 한국어 자막(한 줄 14자 이내)을 넣어 줘.
분위기: 신뢰감 있는 재테크 채널, 빠른 템포, 잔잔한 비트 배경음악.
아래 6개 장면 대본을 그대로 사용해 줘.

[장면1 0~7초] 얼굴 없이, 촬영 없이, 에이아이로 돈 버는 쇼츠 계정 만드는 법. 60초 안에 알려드립니다.
(화면: 스마트폰, 돈 아이콘, 큰 글씨 "얼굴 없이 AI로")

[장면2 7~17초] 첫째, 주제를 정하세요. 돈이 몰리는 분야는 딱 세 가지, 건강, 재테크, 그리고 연애입니다.
(화면: 하트, 동전, 커플 아이콘이 차례로 등장)

[장면3 17~29초] 둘째, 대본은 클로드에게 맡기세요. "건강 쇼츠 60초 대본 써 줘" 한 줄이면 첫 문장부터 마무리까지 완성됩니다.
(화면: 채팅창에 요청문 입력 → 대본이 자동으로 채워지는 모습)

[장면4 29~41초] 셋째, 영상은 에이아이 영상 도구로 만드세요. 가상 인물이나 모션그래픽으로, 내 얼굴 없이 영상이 나옵니다.
(화면: 흐름도 "대본 → AI 영상 도구 → 완성 영상")

[장면5 41~51초] 넷째, 7일 동안 매일 올리고 반응을 확인하세요. 단, 질 낮은 영상을 찍어내기만 하면 신뢰를 잃습니다.
(화면: 달력 7칸 체크, 경고 표지판)

[장면6 51~60초] 결론, 에이아이는 도구일 뿐, 돈은 기획력이 법니다. 팔로우하고 다음 꿀팁도 받아 가세요.
(화면: 체크 표시, "기획력" 강조, 팔로우 버튼)
```

## [D] 썸네일 (쇼츠 커버)

쇼츠는 영상 속 한 장면을 골라 썸네일로 쓰는 방식이 기본입니다. 그래서 장면1을 썸네일용 화면으로 만들어 둡니다.

Mirra 입력문 [B]의 맨 끝에 아래 문장을 붙여넣으세요.

```
장면1의 처음 2초는 썸네일로 쓸 화면이야.
화면 중앙에 큰 글씨 2줄 "얼굴 없이 / AI로 돈 벌기"를 노란색 굵은 글씨, 검은 테두리로 넣어 줘.
배경은 어두운 남색, 스마트폰과 돈 아이콘. 글씨는 화면 위아래 15%를 피해서 중앙에 배치.
```

업로드할 때 커버 고르는 법:
- 휴대폰 YouTube 앱: 업로드 → 세부정보 화면에서 연필(커버) 아이콘 → 큰 글씨가 나오는 장면 선택
- 이미 올린 영상: YouTube 앱 → 내 동영상 → 해당 쇼츠 → 수정 → 썸네일(커버) 변경
