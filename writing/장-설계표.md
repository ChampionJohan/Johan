# 쓰는 법

장 하나에 표 하나입니다. **쓰기 전에 채웁니다.**

빈 칸이 있으면 그 장은 아직 쓸 준비가 안 된 것입니다.
특히 **사례**와 **안 푸는 것** 둘이 비면 쓰기 시작하지 마세요.

- 사례가 없으면 그 장은 일반론이 됩니다
- 안 푸는 것이 없으면 그 장은 너무 매끈해집니다

표는 원고에 안 들어갑니다. 쓰는 동안만 보는 것입니다.
이 파일을 복사해서 `<책>/설계/NN-<가제>.md` 로 두시면 됩니다.

---

# 빈 표

```
## N장 · <가제>

| 칸 | 적을 것 |
|---|---|
| **이 장의 한 문장** | 이 장에서 움직이는 것 하나. 명사 말고 움직임으로 |
| **여는 모양** | 장면 / 질문 / 결론부터 / 앞 장에서 못 푼 것 |
| **사례** | 언제·어디서·누가 + 어디서 확인했는지 |
| **뺀 사례** | 확인이 안 돼서 뺀 것. 「이 장의 출처」에 그대로 들어감 |
| **작가의 구체** | 작가만 아는 것 한 개. 없으면 `<!-- 확인: 겪은 일 -->` 로 비워 둠 |
| **안 푸는 것** | 이 장에서 답 안 하고 넘어갈 것 하나 |
| **「정리하면」** | 붙임 / 안 붙임 — 절반의 장에만 |
| **끝내는 모양** | 다음 장으로 넘김 / 질문으로 닫음 / 할 것 하나 |
| **앞뒤 연결** | 어느 장을 받고, 어느 장으로 넘기는지 |
```

# 채운 보기

## 2장 · 먼저 걸어 두면 달라진다

| 칸 | 적을 것 |
|---|---|
| **이 장의 한 문장** | 잃을 것을 먼저 내놓으면 안 믿던 사람이 믿기 시작한다 |
| **여는 모양** | 장면 — 계약금을 건네는 자리 |
| **사례** | <!-- 확인: 보증금 제도가 언제부터 있었는지 공개 자료로 대조할 것 --> |
| **뺀 사례** | (아직 없음) |
| **작가의 구체** | <!-- 확인: 겪은 일 — 작가가 먼저 돈을 걸어 본 일 한 개 --> |
| **안 푸는 것** | 얼마를 걸어야 믿어지는지. 그 금액을 정하는 법은 나도 모른다 |
| **「정리하면」** | 붙임 |
| **끝내는 모양** | 다음 장으로 — 걸 것이 없는 사람은 어떻게 하나 |
| **앞뒤 연결** | 1장(먼저 주는 쪽)을 받고, 3장(걸 것이 없을 때)으로 넘김 |

**빈 칸 둘을 `<!-- 확인: -->` 로 적어 뒀습니다.**

설계표는 원고가 아니라서 `--stat` 이 여기까지 세지 않습니다.
**그 표시를 원고의 그 자리에도 같이 박아 두세요.** 원고에 있어야 세어지고,
세어져야 안 채운 채로 발행되는 일이 없습니다.

# 한 부를 다 채우고 나서 볼 것

장 설계표를 그 부의 장 수만큼 채웠으면, **세로로 읽어 봅니다.**

| 볼 것 | 걸리면 |
|---|---|
| **여는 모양**이 다 같은가 | 섞습니다. 넷 중 하나로 쏠리면 안 됩니다 |
| **「정리하면」**이 절반을 넘나 | 뺍니다 |
| **안 푸는 것**이 서로 비슷한가 | 하나는 다른 종류로 바꿉니다 |
| **사례**가 한 분야에 몰렸나 | 분야를 벌립니다 |
| **작가의 구체**가 비었나 | 그 부는 아직 못 씁니다 |

마지막 줄이 제일 중요합니다.
**작가의 구체가 하나도 없는 부는 쓰기 시작하면 안 됩니다.**
쓰고 나서 끼워 넣으면 그 자리만 떠 보입니다.
