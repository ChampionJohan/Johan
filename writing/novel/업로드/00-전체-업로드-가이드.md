# 루프 연대기 1~7권 — KDP 업로드 전체 가이드

시리즈 완결. 이 폴더 하나만 있으면 1~7권을 전부 올릴 수 있습니다.

```
업로드/
  00-전체-업로드-가이드.md        ← 이 문서
  1권-loop-chronicles/
    01-loop-chronicles-EN-영어.epub    ← KDP에 올리는 원고
    01-loop-chronicles-EN-영어.pdf     ← 검토용
    01-loop-chronicles-ko-한국어.epub  ← 한국어판 (갓피플 등)
    01-loop-chronicles-ko-한국어.pdf
    01-loop-chronicles-표지.jpg        ← KDP에 올리는 표지
    01-KDP-업로드-순서.md              ← 이 권만의 상세 순서
  2권-the-weeping-ledger/  … 7권-the-last-room/  (구성 동일)
```

**KDP에 올리는 건 `EN-영어.epub` 과 `표지.jpg` 두 개뿐입니다.**
PDF는 미리보기·검토용이고, `ko-한국어` 파일은 국내 연재/배포용입니다.

## 시작 전에 — 이것만은 꼭

**① 시리즈는 한 번만 만듭니다.**
1권을 올릴 때 `Loop Chronicles` 시리즈를 **새로 만들고**, 2~7권은
반드시 **기존 시리즈를 목록에서 선택**합니다. 권마다 새로 만들면
별개 시리즈 7개가 생기고 연결이 끊깁니다.

**② Book Title 칸에는 제목만.**
`Series title:` 같은 라벨을 같이 붙여넣지 마세요. 1권 등록 때 실제로
있었던 실수입니다. 저장 직후 그 칸을 한 번 더 확인하세요.

**③ 표지는 JPG만 됩니다.** PNG는 업로드가 막힙니다.

**④ 표지 업로드 버튼이 안 눌리면** 원고(EPUB)를 먼저 올린 뒤 다시
시도하세요.

**⑤ Sexually Explicit 항목을 먼저 고르세요.** 그걸 골라야 Categories
버튼이 활성화됩니다.
