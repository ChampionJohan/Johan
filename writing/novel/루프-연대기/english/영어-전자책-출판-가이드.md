# 『Loop Chronicles』 영어 전자책 출판 완전 가이드

10년 넘게 출판사에서 편집·제작·유통을 담당해 온 사람의 입장에서, 처음
전자책을 내는 저자에게 설명하듯 처음부터 끝까지 정리했습니다. 순서대로
따라오시면 됩니다.

---

## 0. 큰 그림 먼저

전자책 출판은 크게 네 단계입니다.

1. **원고 준비** — 번역, 교정, 성경 인용 저작권 확인 (완료 시 이 문서와 함께 전달)
2. **파일 제작** — EPUB(전자책 파일), PDF(인쇸/미리보기용), 표지 이미지
3. **플랫폼 등록** — 아마존 KDP가 사실상 필수, 나머지는 선택
4. **출간 후 관리** — 가격, 카테고리, 리뷰, 마케팅

이 중 1~2단계는 이번 작업으로 준비해 드립니다. 3~4단계는 **본인 명의
계좌·세금 정보·저자명**이 필요하기 때문에 대신 클릭해 드릴 수 없는
부분이지만, 화면 항목 하나하나를 정확히 알려드리겠습니다.

## 1. 플랫폼 선택 — 어디에 낼 것인가

| 플랫폼 | 특징 | 추천도 |
|---|---|---|
| **Amazon KDP** (Kindle Direct Publishing) | 전 세계 전자책 시장의 60~80%. 무료 가입, 무료 등록, 로열티 35%/70% 선택 | ★★★★★ 필수 |
| **Draft2Digital (D2D)** | 한 번 등록으로 Apple Books, Barnes & Noble, Kobo, 스매시워즈 등에 동시 배급. 무료 | ★★★★☆ 강력 추천 |
| **Apple Books (Apple Books for Authors)** | 아이폰/아이패드 사용자층. 직접 등록도 가능하지만 D2D를 거치는 게 훨씬 간편 | ★★★☆☆ (D2D로 대체 가능) |
| **Google Play Books Partner Center** | 검토 절차가 있고 심사 기간이 김. 직접 등록 | ★★★☆☆ |
| **Kobo Writing Life** | 캐나다·유럽에서 강세. D2D로도 커버됨 | ★★☆☆☆ |

**결론**: 처음엔 **KDP 단독 등록**으로 시작하는 것을 권합니다. 이유는:
- 절차가 가장 간단하고 문서화가 잘 되어 있음
- "KDP Select"라는 90일 독점 프로그램에 넣으면 Kindle Unlimited(구독)
  수익이 추가로 발생 — 다만 이 기간엔 다른 곳에 전자책을 못 냄
- 반응을 본 뒤, 90일 뒤 KDP Select를 해지하고 D2D로 확장해 Apple/Kobo까지
  넓히는 게 정석 루트

## 2. 원고 파일 준비 — 무엇을, 어떤 형식으로

### 2-1. 필요한 파일
1. **원고 EPUB 파일** — 이번에 `loop-chronicles-en.epub`으로 제작해 드립니다. KDP는
   업로드 시 자동으로 자체 포맷(KFX)으로 변환하므로, EPUB만 있으면 됩니다.
   (docx나 PDF도 업로드는 되지만, 대화가 많고 이탤릭체 반영이 중요한
   소설은 EPUB이 훨씬 안전합니다.)
2. **표지 이미지** — 아래 2-3 참고. 이건 제가 텍스트만으로 만들어 드릴 수
   없는 유일한 조각입니다 (일러스트/디자인 작업 필요).
3. **책 소개 문구(Book Description)** — 아래 4장에서 같이 작성합니다.

### 2-2. EPUB 파일 요건 (KDP 기준)
- 크기: 650MB 이하 (이 책은 챕터 48개, 텍스트 전용이라 1MB 안팎 — 문제 없음)
- 목차(내비게이션)가 있어야 함 — 제작한 EPUB에 이미 포함됨
- 챕터마다 별도 파일로 분리 — 이미 그렇게 되어 있음
- 이미지 삽입 시 72~150 DPI 권장 — 이 책은 표지 외 삽화 없음

### 2-3. 표지 이미지 요건 (매우 엄격하게 봅니다)
- **크기**: 최소 1000×1600px, 권장 **2560×1600px** (가로:세로 = 1:1.6)
- **형식**: JPEG 또는 TIFF, RGB 색상 (CMYK 안 됨)
- **용량**: 50MB 이하
- 표지에 다른 책 표지를 베끼거나 저작권 있는 이미지·폰트를 무단 사용하면
  안 됩니다. 무료 상업적 이용 가능 소스로는:
  - Canva (전자책 표지 템플릿 무료/유료 혼합)
  - Unsplash / Pexels (배경 이미지, 상업적 이용 무료)
  - 직접 의뢰: Fiverr, 99designs (5~50달러대 표지 디자이너 다수)
- 원하시면 표지 디자인용 **프롬프트 문구**(AI 이미지 생성용)나 Canva
  구도 가이드를 별도로 만들어 드릴 수 있습니다 — 말씀해 주세요.

## 3. Amazon KDP 가입 및 등록 — 화면 항목별 안내

### 3-1. 계정 만들기
1. https://kdp.amazon.com 접속 → **Sign up** (기존 아마존 계정으로도 가능하나,
   저자용 계정은 개인 정보와 세금 정보가 묶이므로 별도 아마존 계정 권장)
2. **저자/출판사 정보 입력**: Author/Publisher name, Address, Phone
3. **세금 인터뷰(Tax Information)** — 가장 많이 막히는 단계입니다.
   - 한국 거주자는 **미국 비거주 외국인(Non-US person)** 으로 진행
   - "Tax Identity" 인터뷰에서 국적 확인 → 한미 조세 조약 적용 여부 자동 판단
   - **개인 납세자 번호가 없다면** 한국 국세청 발급 사업자등록번호나
     주민등록번호 기반 정보로 진행 가능 (인터뷰가 안내하는 대로 선택)
   - 조세 조약 덕분에 로열티 원천징수세가 30% → 대개 0~10%로 낮아집니다.
     (정확한 세율은 인터뷰 종료 시 화면에 표시됩니다.)
4. **은행 계좌 등록** — 로열티 지급용. 한국 은행 계좌(SWIFT 코드 필요)도
   등록 가능합니다. 국내 은행에서 "해외송금 받기"가 가능한 계좌인지
   미리 확인하세요 (대부분의 시중은행 가능).

### 3-2. "Bookshelf → Create" 새 전자책 등록 (Kindle eBook)

**Details 탭**
- **Language**: English
- **Book Title**: `Loop Chronicles`
- **Subtitle** (선택): `A Novel` 또는 시리즈성이 있다면 `Book One` 등
- **Series** (선택): 후속작 계획이 있다면 "Loop Chronicles" 시리즈로 등록해
  2권부터 자동으로 묶여 노출됩니다.
- **Edition number**: 최초 등록이면 비워둠
- **Author**: 본인 성함 또는 필명 — **한 번 등록하면 이후 책도 같은 이름
  으로 통일하는 게 브랜딩에 유리**합니다.
- **Contributors**: 번역자를 별도 표기하고 싶다면 "Translator" 역할로 추가 가능
- **Description**: 4장 참고 (최대 4,000자, HTML 태그 일부 허용 — `<b>`, `<i>`, `<br>`)
- **Publishing Rights**: "This is not a public domain work" 선택 (본인 창작물이므로)
- **Keywords**: 최대 7개. 예시:
  `christian fantasy`, `christian young adult fiction`, `daniel prophecy fiction`,
  `time loop fantasy`, `allegorical christian fiction`, `AI dystopia christian`,
  `coming of age christian fiction`
  (검색 유입의 핵심 항목이니 실제 등록 직전에 다시 다듬어 드릴 수 있습니다.)
- **Categories**: 최대 3개(신청 후 2개 추가 요청 가능, 총 5개까지). 추천:
  - Fiction → Christian → Fantasy
  - Fiction → Coming of Age
  - Fiction → Science Fiction & Fantasy → Fantasy → Dark Fantasy
    또는 Teen & Young Adult → Fantasy & Magic → Religious
- **Age range**: 13-18세 (YA) 권장

**Kindle eBook Content 탭**
- **Manuscript**: `loop-chronicles-en.epub` 업로드
- **Kindle eBook Cover**: 표지 이미지 업로드 (2-3 참고)
- 업로드 후 "Preview" 버튼으로 **Kindle Previewer**가 열립니다 — 실제
  킨들 화면처럼 미리보기 필수 확인 (챕터 이동, 이탤릭체, 특수문자 깨짐 여부)

**Kindle eBook Pricing 탭**
- **KDP Select 등록 여부**: 처음엔 등록 권장 (Kindle Unlimited 수익 + 무료
  프로모션 5일 사용 가능). 단, 90일간 이 EPUB을 다른 곳(D2D 등)에 못 올림.
- **Territories**: All territories (전 세계) 권장
- **Royalty**: 
  - 70% 로열티 옵션은 가격이 $2.99~$9.99 사이일 때만 가능 (전송비 차감)
  - 35% 로열티는 가격 제한 없음
  - **소설 데뷔작 추천가**: $3.99~$4.99 (70% 로열티 구간, 페이지 수 대비
    합리적인 체감가)
- **Price**: 위에서 정한 가격을 지역별로 설정 (기본은 자동 환산되지만
  주요 시장인 US/UK 가격은 직접 확인 권장)

**최종 확인 → Publish**
- 제출 후 보통 **24~72시간** 내 심사(자동+수동 혼합) 후 게시
- 게시되면 `amazon.com/dp/[ASIN]` 형태의 고유 링크 생성

## 4. 책 소개(Description) 쓰는 법 — 실제 초안

KDP Description 칸에 그대로 넣으시면 됩니다 (필요시 다듬어 드릴게요):

> For three hundred years, no one in this city has ever finished anything.
>
> When Temel, Mena, and Speon fall through a sealed page of Daniel's
> prophecy into a place where every bridge is built overnight and nothing
> is ever truly lived — they meet an AI that answers every question except
> "why," and a barefoot stranger no one else can quite see.
>
> Loop Chronicles is a Christian fantasy for readers who grew up on Narnia
> and now wonder what faith looks like across a screen. It asks the
> question at the heart of an AI age: if a machine can answer anything,
> what is a person for?
>
> A story about denial, betrayal, and the strange comfort of being fully
> known — and the discovery that the record of it all was written before
> it ever began.

## 5. 성경 인용 저작권 — 이미 안전하게 처리했습니다

이번 영어 번역본은 전부 **킹제임스역(KJV)**을 사용했습니다. KJV는 전 세계
공유 저작물(public domain)이라 상업 출판에 인용료나 허가가 필요 없습니다.
NIV·ESV·NASB 등 현대 번역본은 저작권이 있어 상업적으로 다량 인용하려면
성경 출판사(Zondervan, Crossway 등)의 별도 허가와 인용료가 필요하니,
**절대 다른 번역본으로 바꾸지 마세요.** 이 부분은 법적으로 가장 중요한
지점이라 미리 처리해 두었습니다.

## 6. 한국어판은 어떻게 하나 — 별도 트랙

한국어판은 **국내 플랫폼**이 따로 있고, 아마존 KDP에도 한국어 전자책을
낼 수 있습니다 (Language를 Korean으로 설정하면 됨). 국내 유통을 고려한다면:

| 플랫폼 | 특징 |
|---|---|
| **리디북스(RIDI)** | 국내 1위 전자책 서점. 개인 출판(RIDI 오리진) 가능 |
| **교보문고 e북** | 개인 저자 등록 절차 있음 (사업자등록 권장) |
| **밀리의 서재** | 구독형, 입점 심사 있음 |
| **갓피플(GodPeople)** | 기독교 콘텐츠 특화 — 이미 이 소설을 연재 중인 곳이므로,
  전자책/단행본 출간 문의를 갓피플 측에 직접 넣는 것이 가장 자연스러운
  경로입니다. 출판사 계약 형태(정식 단행본)로 가는 것도 고려해 볼 만합니다. |

한국 ISBN이 필요하면 **국립중앙도서관 한국서지표준센터**에서 출판사
등록 후 무료로 발급받습니다 (개인도 "1인 출판사" 형태로 등록 가능).

## 7. 흔히 놓치는 것들 (체크리스트)

- [ ] 저작권 페이지에 실제 연도·저자명 넣기 (`Copyright © 2026 [저자명]. All rights reserved.`)
- [ ] 오탈자 교정 — 가능하면 원어민 교정자(Fiverr, Reedsy에서 $100~$300대)에게
  한 번 더 검수 받는 것을 강력 추천 (번역 투 문장이 남아있을 수 있음)
- [ ] Kindle Previewer로 실제 기기 화면 확인
  (https://www.amazon.com/Kindle-Previewer/b?node=21381691011)
- [ ] 미국 저작권청(U.S. Copyright Office) 등록은 필수는 아니지만, 표절
  분쟁 시 법적 증거력이 커짐 — $45, https://www.copyright.gov (선택사항)
- [ ] 시리즈로 이어갈 계획이면 KDP에서 "Series" 등록해 두기
- [ ] 출간 후 Amazon Author Central(https://authorcentral.amazon.com)에서
  저자 프로필 페이지 만들기 — 무료, 검색 노출에 도움

## 8. 출간 이후 — 최소한의 마케팅

1. **ARC(사전 독자) 리뷰 확보** — BookSirens, Booksprout 같은 무료/저가
   서비스로 리뷰어에게 무료 EPUB을 배포하고 정직한 리뷰를 요청
2. **Goodreads 등록** — 작가 계정 만들고 책 등록 (무료)
3. **가격 프로모션** — KDP Select 안에서 5일 무료 프로모션 1회 사용 가능,
   초반 다운로드 수 확보에 유용
4. **갓피플 연재 독자층 활용** — 이미 한국어로 쌓인 독자가 있으니, 완결
   공지에 영어판 링크를 함께 announce하면 초기 트래픽 확보에 도움
