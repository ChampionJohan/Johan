쓰는 법

장 하나에 표 하나입니다. 쓰기 전에 채웁니다.

빈 칸이 있으면 그 장은 아직 쓸 준비가 안 된 것입니다. 특히 사례와 안 푸는 것 둘이 비면 쓰기 시작하지 마세요.

  • 사례가 없으면 그 장은 일반론이 됩니다
  • 안 푸는 것이 없으면 그 장은 너무 매끈해집니다

표는 원고에 안 들어갑니다. 쓰는 동안만 보는 것입니다. 이 파일을 복사해서 <책>/설계/NN-<가제>.md 로 두시면 됩니다.

빈 표

## N장 · <가제>

| 칸 | 적을 것 |
|---|---|
| **이 장의 한 문장** | 이 장에서 움직이는 것 하나. 명사 말고 움직임으로 |
| **여는 모양** | 장면 / 질문 / 결론부터 / 앞 장에서 못 푼 것 |
| **사례** | 언제·어디서·누가 + 어디서 확인했는지 |
| **뺀 사례** | 확인이 안 돼서 뺀 것. 「이 장의 출처」에 그대로 들어감 |
| **작가의 구체** | 작가만 아는 것 한 개. 없으면 `<!-- 확인: 겪은 일 -->` 로 비워 둠 |
| **안 푸는 것** | 이 장에서 답 안 하고 넘어갈 것 하나 |
| **「정리하면」** | 붙임 / 안 붙임 — 절반의 장에만 |
| **끝내는 모양** | 다음 장으로 넘김 / 질문으로 닫음 / 할 것 하나 |
| **앞뒤 연결** | 어느 장을 받고, 어느 장으로 넘기는지 |
