# 일기 작성 규칙

하루를 돌아보며 남기는 기록이다. 매체에 낼 원고(`writing/posts`)와 다르다.

## 일하는 방식

필자가 메모를 던지고, 자동 작성기가 살을 붙인다.

```
"9월 24일 (목) 버스 6시간 타고 싱가포르. 이스라엘 형제 만나 저녁, 시내 구경. 감사."
        ↓
writing/diary/2026-09-24.md  +  writing/diary/html/2026-09-24.html
```

## 살을 붙일 때 지키는 것

1. **메모에 없는 사실은 쓰지 않는다.** 식당 이름, 요금, 인원, 소요 시간을 추측해 채우지 않는다.
   확인이 필요한 항목은 `## 메모 (채울 것)` 아래에 빈 줄로 남긴다.
2. **채우는 것은 흐름과 생각이다.** 메모의 사실을 순서대로 정리하고,
   그 사실에서 자연히 나오는 생각·연결·기도를 붙인다.
3. **앞선 일기와 연결한다.** 같은 장소, 같은 사람, 같은 주제가 이어지면 그 흐름을 적는다.
4. **날짜와 요일은 계산해서 확인한다.** 메모의 요일이 실제와 다르면 그 사실을 알린다.

## 기본 구성

```
## 오늘 있었던 일     사실. 일정이 여러 개면 표로.
## (그날의 주제)      그 사실에서 나오는 생각 한 덩이. 제목은 그날마다 다르게.
## 메모 (채울 것)     필자만 아는 것들. 빈 줄로 남긴다.
## 기도              그날의 기도 2~3줄.
```

## 명령어

```
python3 tools/diary.py new           # 오늘자 뼈대 (날짜·요일 자동, 일요일은 '주일')
python3 tools/diary.py new 2026-09-26
python3 tools/diary.py build         # 전체 HTML 재생성
```
