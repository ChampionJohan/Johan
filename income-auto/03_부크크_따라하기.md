# 부크크 출간, 순서대로

**전제**: 크몽 전자책 원고(`kmong/03_전자책원고.md`)가 완성돼 있어야 합니다.
원고가 없으면 이 문서는 아직 쓸 수 없습니다. 먼저 3주차 작업을 끝내십시오.

**총 4~5시간.** 원고를 새로 쓰지 않기 때문에 이 정도에서 끝납니다.

> 부크크 화면의 메뉴 이름과 옵션은 바뀝니다. 아래와 다르면 **기능**으로 찾으십시오.
> 공식 사이트: https://www.bookk.co.kr

## STEP 0. 먼저 정할 것 3가지 (20분)

**이 셋은 출간 후 되돌릴 수 없습니다.** ISBN이 붙고 공공도서관에 납본되기 때문입니다.

### 결정 1. 저자명 — 실명인가 필명인가

| | 실명 | 필명 |
|---|---|---|
| 크몽 프로필 연결 | 바로 된다 | 설명이 필요하다 |
| 겸직 노출 | **회사가 검색으로 찾을 수 있다** | 찾기 어렵다 |
| 신뢰 | 높다 | 낮다 |

- [ ] 결정: ______________
- 판단 기준: STEP 0 이전에 **취업규칙 겸직 조항을 확인**했는가. 확인하고 문제가 없으면 실명이 낫습니다.
- 애매하면 필명으로 시작합니다. 필명으로 낸 책을 나중에 실명으로 밝힐 수는 있지만, 반대는 안 됩니다.

### 결정 2. 종이책도 낼 것인가

**둘 다 내십시오.** 부크크 종이책은 주문이 들어올 때 인쇄하는 방식(POD)이라 **재고 부담이 없습니다.**

"교보문고에서 검색되는 책"이라는 한 줄이 크몽 전환율을 올립니다.
전자책만 내면 그 효과가 약합니다.

- [ ] 종이책 + 전자책 둘 다 (권장)
- [ ] 전자책만

### 결정 3. 원고에서 지울 것 최종 점검

ISBN이 붙으면 **회수할 수 없습니다.** 지금이 마지막 기회입니다.

- [ ] 발주처 실명 + 사업명 조합
- [ ] 계약 금액, 계약 조건
- [ ] 재직 회사명
- [ ] 특정 인물이 식별되는 일화
- [ ] 실제 산출물 화면·구성도
- [ ] 내부 시스템명, 계정, IP

찾는 법: 원고 파일에서 기관명·회사명을 하나씩 검색합니다. 눈으로 읽어서는 놓칩니다.

### 판형은 A5 계열로

| 판형 | 특징 | 판정 |
|---|---|---|
| A5 (148×210) | 실용서 표준. 표·목록이 읽힌다 | **권장** |
| 46판 (127×188) | 소설·에세이용. 표가 좁아진다 | 비권장 |
| B5 (182×257) | 워크북·교재용. 제작비가 오른다 | 상황에 따라 |

이 원고에는 **표가 많습니다.** 좁은 판형을 고르면 표가 깨집니다. A5가 무난합니다.

## STEP 2. 원고 정리 (2시간)

크몽용 PDF와 종이책 원고는 다릅니다. 판형에 맞춘 여백, 쪽번호, 목차가 필요합니다.
**내려받은 표준 양식에 내용을 붙여넣는 방식**으로 작업합니다. 새 문서에서 시작하지 마십시오.

### 책에는 있고 크몽 PDF에는 없는 것

순서대로 넣습니다.

| 순서 | 요소 | 분량 | 내용 |
|---|---|---|---|
| 1 | 속표지 | 1쪽 | 제목 / 부제 / 저자명 |
| 2 | 머리말 | 2쪽 | **왜 이 책을 썼는가** |
| 3 | 목차 | 1~2쪽 | 장 제목 + 쪽번호 |
| 4 | 본문 | — | 기존 원고 |
| 5 | 맺으며 | 1쪽 | 기존 원고에 있음 |
| 6 | 저자 소개 | 1쪽 | 회사명 없이 |
| 7 | 판권지 | 1쪽 | 서지정보. 양식에 포함돼 있음 |

### 머리말에 쓸 것

가장 많이 비워 두는 부분이고, 서점에서 **미리보기로 가장 많이 읽히는 부분**입니다.

```
1문단 — 독자가 지금 겪고 있는 상황
2문단 — 그 상황에서 아무도 알려주지 않는 것
3문단 — 이 책이 그중 무엇을 다루는가
4문단 — 이 책이 다루지 않는 것 (정직하게)
```

`kmong/02_서비스문안.md` 의 "이런 상황이라면" 부분을 고쳐 쓰면 됩니다.

### 저자 소개 — 회사명 없이 쓰는 법

```
공공 IT 운영·구축 사업의 관리 업무를 (N)년간 해 왔다.
착수부터 검사·인수까지의 문서를 만들고, 고치고, 검사받는 자리에 있었다.
(보유 자격)
```

**재직 회사와 발주처는 쓰지 않습니다.** 역할과 기간만으로 충분합니다.

### 판권지에서 확인할 것

- [ ] **개인 주소·연락처가 노출되는 항목이 있는지 확인**

자가출판에서는 저자 정보가 판권지에 들어갈 수 있습니다.
공개 범위를 반드시 확인하고, 노출을 원하지 않으면 입력하지 않거나 대체합니다.

### 마지막 점검

- [ ] 2-1. 쪽번호가 모든 쪽에 들어갔는가
- [ ] 2-2. 목차의 쪽번호가 실제와 맞는가
- [ ] 2-3. 표가 판형 밖으로 나가지 않는가 (인쇄 미리보기로 확인)
- [ ] 2-4. `<!-- TODO -->` 가 하나도 남아 있지 않은가 ← **검색으로 확인**
- [ ] 2-5. 소리 내어 1회 통독

4번을 놓치면 주석이 책에 그대로 인쇄됩니다.

- [ ] 3-1. 부크크 **표지 만들기** 도구 진입 (무료 템플릿 제공)

### 표지 원칙 세 가지

1. **제목이 썸네일에서 읽혀야 합니다.** 서점 목록에서는 손톱만 하게 보입니다
2. 사진을 넣지 않습니다. 저작권 문제 + 축소하면 뭔지 모릅니다
3. 색은 2가지까지. 짙은 배경 + 밝은 글자가 가장 안전합니다

### 폰트 저작권

- [ ] 3-5. **상업적 이용이 허용된 폰트인지 확인**

무료 폰트라도 인쇄물·상업적 이용이 제한된 경우가 있습니다.
상업용 무료 폰트 모음: https://noonnu.cc — 각 폰트의 허용 범위를 직접 확인하고 씁니다.

## STEP 5. 가격과 유통 (20분)

### 종이책 정가

부크크가 쪽수에 따라 제작비를 산정합니다. **최소 정가 아래로는 못 내립니다.**

- [ ] 5-1. 시스템이 제시하는 최소 정가 확인
- [ ] 5-2. 최소 정가보다 2,000~4,000원 위로 설정

실용서 A5 기준 15,000~19,000원대가 일반적인 구간입니다.
**너무 싸게 매기지 마십시오.** 싼 실용서는 신뢰가 떨어집니다.

### 전자책 가격 — 크몽과 충돌하지 않게

여기서 실수가 잘 납니다. 같은 내용을 크몽보다 싸게 팔면 크몽 구매자가 손해를 봅니다.

| 채널 | 가격 | 구성 |
|---|---|---|
| 크몽 전자책 | 19,900원 | 본편 + **부록 템플릿 4종** |
| 부크크 전자책 | 9,900~12,000원 | 본편만 |
| 부크크 종이책 | 15,000~19,000원 | 본편만 |

**부록 템플릿을 크몽에만 두는 것**으로 가격 차이를 설명합니다.
같은 물건을 두 값에 파는 게 아니라, 구성이 다른 것입니다.

- [ ] 5-3. 부록은 크몽에만 넣는다 (부크크 원고에서 템플릿 부분 제외)

### 유통 범위

- [ ] 5-4. 부크크 자체몰 + **외부 서점 유통 신청** (교보문고·예스24·알라딘 등)

외부 유통이 이 작업의 핵심입니다. **"교보문고에서 검색되는 책"이 목적**이기 때문입니다.
유통 조건과 정산 차이는 STEP 1 확인표에서 확인한 값을 따릅니다.

### 왜 이 순서가 돈이 되는가

```
99,000원 첨삭을 파는 사람   →  "이 사람이 잘하나?"  →  이탈
같은 가격 + 해당 분야 저서  →  "아, 이 분야 사람이구나"  →  구매
```

책 한 권이 **상품 3개의 전환율을 동시에 올립니다.**
그래서 인세가 적어도 손해가 아닙니다. 들인 시간은 4~5시간뿐입니다.

## 막힐 때

| 상황 | 이렇게 합니다 |
|---|---|
| 원고 분량이 최소 페이지에 못 미친다 | 부록으로 산출물 체크리스트를 본문에 넣습니다. 여백·판형을 늘리지 않습니다 |

| 심사가 오래 걸린다 | 그동안 크몽 리뷰를 쌓습니다. 기다리는 시간에 할 일이 따로 있습니다 |
