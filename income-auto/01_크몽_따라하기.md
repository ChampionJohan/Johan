# 크몽 가입 다음, 순서대로

**가입은 시작이 아니라 준비입니다.** 가입만 하면 아무 일도 일어나지 않습니다.
상품이 등록되고 심사를 통과해야 판매가 시작됩니다. 거기까지 **총 3시간**입니다.

> 크몽 화면의 메뉴 이름은 수시로 바뀝니다. 아래 이름과 다르면 **기능**으로 찾으십시오.
> (예: "전문가 등록"이 "전문가 전환"이나 "판매 시작하기"일 수 있습니다)

## 전체 지도

| 단계 | 하는 일 | 시간 | 끝나면 |
|---|---|---|---|
| 1 | 전문가 전환 | 15분 | 판매자 계정이 된다 |
| 2 | 프로필 작성 | 25분 | 구매자가 보는 내 소개가 생긴다 |
| 3 | 경쟁 조사 | 30분 | 가격의 근거가 생긴다 |
| 4 | 가격 확정 | 10분 | 숫자가 정해진다 |
| 5 | 서비스 등록 | 60분 | 상품이 만들어진다 |
| 6 | 썸네일 제작 | 30분 | 목록에 뜰 이미지가 생긴다 |
| 7 | 제출 | 10분 | 심사 대기 |

**1~2단계는 오늘, 3~7단계는 이번 주 안에.** 한 번에 다 하려 하지 않아도 됩니다.

---

## STEP 1. 전문가 전환 (15분)

가입한 계정은 아직 **구매자** 계정입니다. 판매하려면 전환이 필요합니다.

- [ ] 1-1. 크몽 로그인 → 우측 상단 프로필 → **전문가 등록 / 전문가 전환** 클릭
- [ ] 1-2. 활동 유형 선택 → **개인(비사업자)** 선택
  - 사업자등록 없이 시작할 수 있습니다. 매출이 쌓이면 그때 등록해도 늦지 않습니다
- [ ] 1-3. 휴대폰 본인인증
- [ ] 1-4. 정산 계좌 등록 — **반드시 본인 명의** 계좌
- [ ] 1-5. 전환 완료 확인

### 여기서 같이 메모할 것

판매 조건은 플랫폼이 바꿉니다. 화면에서 보이는 값을 직접 적어 두십시오.

| 항목 | 확인한 값 | 확인 날짜 |
|---|---|---|
| 판매 수수료율 | | |
| 정산 주기 | | |
| 정산 신청 최소 금액 | | |

확인 위치: 크몽 고객센터 https://kmong.com/help

**왜 적어 두나**: 가격을 정가가 아니라 **내 손에 들어오는 금액**으로 계산해야 하기 때문입니다.
99,000원짜리를 팔아도 수수료를 떼면 그만큼 들어오지 않습니다.

---

## STEP 2. 프로필 작성 (25분)

구매자는 상품을 보고, 그다음 **파는 사람**을 봅니다. 프로필이 비어 있으면 거기서 이탈합니다.

- [ ] 2-1. 프로필 사진 등록 — 얼굴 사진이 가장 낫습니다. 어려우면 단정한 단색 배경 이미지
- [ ] 2-2. 한 줄 소개 작성
- [ ] 2-3. 경력 작성
- [ ] 2-4. 보유 자격 입력

### 한 줄 소개 예시

```
공공 IT 운영·구축 사업 관리 15년. 서류에서 안 보이던 경력을 보이게 고칩니다.
```

구조는 **경력 사실 + 내가 해결하는 문제** 두 조각입니다.
"최선을 다하겠습니다", "믿고 맡겨 주세요" 같은 문장은 넣지 않습니다. 정보가 0입니다.

### 경력 작성 규칙 세 가지

1. **회사명은 쓰지 않습니다.** "IT 서비스 기업 재직"으로 충분합니다 (겸직 노출 위험 차단)
2. **발주처·사업명은 쓰지 않습니다.** "공공기관 운영사업 관리"로 일반화합니다
3. 숫자는 씁니다. "15년", "동시 3개 사업", "연 20명 규모"는 사실이면 강력합니다

## STEP 3. 경쟁 조사 (30분) — 이 단계를 건너뛰면 가격이 틀립니다

- [ ] 3-1. 크몽 검색창에 `경력기술서 첨삭` 입력
- [ ] 3-2. 상위 5개 상품을 열어 아래 표를 채웁니다

| # | 제목(앞 15자) | 최저가 | 최고가 | 리뷰 수 | 작업일 |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

- [ ] 3-3. `IT 이력서`, `이직 컨설팅` 으로도 검색해 2개 더 추가

### 조사에서 볼 것은 가격이 아니라 이것입니다

| 보는 것 | 알 수 있는 것 |
|---|---|
| 리뷰 수 | 이 시장에 수요가 있는가 (상위 상품 리뷰 50건 이상이면 수요 충분) |
| 가격 분포 | 내가 들어갈 자리 (최저가 옆은 피합니다) |
| 상세페이지 첫 3줄 | 사람들이 어떤 말에 반응하는가 |
| **없는 것** | **내 자리** ← 가장 중요 |

마지막 줄이 핵심입니다. 상위 5개가 전부 "신입 자소서"를 다루고 있다면,
**IT 사업관리 경력직**은 비어 있는 자리입니다. 거기로 들어갑니다.

---

## STEP 4. 가격 확정 (10분)

조사한 가격 분포에서 **중간값보다 조금 위**를 잡습니다. 최저가는 잡지 않습니다.

기본안:

| 패키지 | 가격 | 제공 |
|---|---|---|
| STANDARD | 49,000원 | A4 3장 이내 검토 의견 |
| DELUXE | 99,000원 | A4 5장 + 수정본 + 3일 질의응답 |

### 최저가로 시작하면 안 되는 이유

첨삭 1건에 90분이 듭니다. 29,000원이면 시급 약 19,000원입니다.
게다가 **가격은 올리기가 내리기보다 훨씬 어렵습니다.** 기존 구매자 리뷰에 가격이 남기 때문입니다.

- [ ] 4-1. 조사표의 중간값 계산
- [ ] 4-2. 내 가격 확정: STANDARD ______원 / DELUXE ______원

## STEP 5. 서비스 등록 (60분)

여기가 본 작업입니다. **`kmong/04_첨삭서비스문안.md` 를 열어 두고** 진행하십시오.
대부분 복사해서 붙여넣으면 됩니다.

- [ ] 5-1. 상단 메뉴 **서비스 등록 / 판매 시작하기** 클릭
- [ ] 5-2. 카테고리 선택 → `문서·글쓰기` → `첨삭·교정` 계열

### 화면 항목별로 무엇을 넣는가

| 입력 화면 항목 | 무엇을 넣나 | 어디서 가져오나 |
|---|---|---|
| 서비스 제목 | 제목안 1~3 중 택 1 | 04_첨삭서비스문안.md A-1 |
| 카테고리 | 문서·글쓰기 > 첨삭·교정 | — |
| 서비스 설명 | 상세 설명 전문 | 04_첨삭서비스문안.md A-3 |
| 패키지 3종 | 가격·제공 범위 | STEP 4에서 정한 숫자 |
| 작업 기간 | 3일 | — |
| 수정 횟수 | STANDARD 1회 / DELUXE 2회 | — |
| 서비스 제공 절차 | 진행 방식 4줄 | 04_첨삭서비스문안.md A-3 |
| FAQ | 5개 | 04_첨삭서비스문안.md A-5 |
| 태그 | 8개 | 04_첨삭서비스문안.md A-2 |

- [ ] 5-3. `<!-- TODO -->` 표시된 곳을 본인 정보로 채웠는지 확인
  - 경력 연수, 보유 자격 두 곳입니다. 그대로 두고 등록하면 반려됩니다

### 반려되는 5가지 — 등록 전 확인

| 넣으면 반려 | 예 |
|---|---|
| 외부 연락처 | 이메일, 카카오톡 ID, 전화번호, 개인 블로그 주소 |
| 타 플랫폼 유도 | "직접 연락 주시면 더 저렴하게" |
| 효과 보장 표현 | "100% 합격", "무조건", "반드시 붙습니다" |
| 저작권 불명 이미지 | 구글에서 받은 사진 |
| 모호한 제공 범위 | "성심껏 봐 드립니다" (몇 장을, 며칠에?) |

- [ ] 5-4. 위 5가지가 본문에 없는지 검색으로 확인

## STEP 6. 썸네일 제작 (30분)

목록에서 사람들이 **가장 먼저 보는 것**이고, 사실상 유일하게 보는 것입니다.

- [ ] 6-1. https://www.canva.com 무료 가입
- [ ] 6-2. 크몽 등록 화면에 표시된 **권장 크기**로 새 디자인 생성
- [ ] 6-3. 단색 배경(짙은 남색 계열) + 텍스트 3줄
- [ ] 6-4. PNG 내려받기 → 업로드

### 텍스트는 3줄까지입니다

```
IT 사업관리·PM
경력기술서 첨삭
15년 실무자가 직접
```

휴대폰 목록에서 실제로 읽히는 건 딱 이 정도입니다.
문장을 넣지 말고 **명사**로 끊으십시오. 이미지는 넣지 않아도 됩니다. 글자가 크면 이깁니다.

---

## STEP 7. 제출과 심사 (10분 + 대기)

- [ ] 7-1. 미리보기로 **휴대폰 화면** 확인 (구매자 대부분이 모바일입니다)
- [ ] 7-2. 제출
- [ ] 7-3. 심사 결과 대기

### 반려되면

당황할 일이 아닙니다. 첫 등록에서 흔합니다.

1. 반려 사유를 `kmong/01_체크리스트.md` 맨 아래 로그 표에 그대로 적습니다
2. 해당 부분만 고칩니다. 전체를 다시 쓰지 않습니다
3. 재제출합니다

## 심사 통과 후 3일 — 여기서 갈립니다

**등록만 하고 기다리면 아무 일도 일어나지 않습니다.** 리뷰 0건 상품은 노출돼도 안 팔립니다.
임계점은 **리뷰 3건**입니다.

| 일 | 할 일 |
|---|---|
| D+1 | 이직 준비 중인 지인·전 동료 3명에게 연락 |
| D+2 | 정가로 구매받고 **실제로 첨삭 수행** (90분 표준 순서는 04번 문서 맨 뒤) |
| D+3 | 결과 발송 → 솔직한 후기 요청 |

### 반드시 지킬 것

**무료로 해 주고 후기만 받으면 안 됩니다.** 대가성 후기로 분류되면 상품이 내려갑니다.
정가로 구매받고, 실제로 서비스를 제공하고, 후기는 정직하게 받습니다.
지인이 부담스러워하면 그 돈으로 밥을 사면 됩니다. 순서가 중요합니다.

## 막힐 때

| 상황 | 이렇게 합니다 |
|---|---|
| 메뉴 이름이 문서와 다르다 | 기능으로 찾습니다. 그래도 없으면 크몽 고객센터 채팅 |
| 카테고리가 애매하다 | 경쟁 상품 상세페이지 상단의 카테고리 경로를 그대로 따라갑니다 |
| 프로필에 쓸 경력이 부족해 보인다 | 15년은 부족하지 않습니다. 회사명 없이 역할과 규모만 씁니다 |
| 등록까지 했는데 조회수가 0 | 제목 키워드 문제입니다. 검색어를 바꿔 제목을 고칩니다 |
| 조회는 있는데 구매가 없다 | 상세페이지 **앞 3줄**을 고칩니다. 썸네일이 아닙니다 |
| 문의는 오는데 결제가 없다 | 가격이 아니라 "무엇이 들어있는지"가 불명확한 경우가 대부분입니다 |
