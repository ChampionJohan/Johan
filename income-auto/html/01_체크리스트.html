A. 계정·정산 준비 (D-14)

  • 크몽 회원가입 → 전문가(판매) 전환 신청
  • 본인 인증 완료
  • 정산 계좌 등록 (예금주 = 가입자 본인 명의)
  • 사업자 여부 결정: 개인(비사업자) / 개인사업자 중 선택
  • 비사업자로 시작 가능. 다만 연간 수입이 쌓이면 사업자 등록·종합소득세 신고 대상이 된다.
  • 판단 기준과 세율은 국세청 기준으로 확인한다: https://www.nts.go.kr/
  • 수수료율·정산 주기 확인 후 아래 표에 직접 기입 (플랫폼이 변경하므로 값을 옮겨 적지 않는다)

  • 분량 확인: 본문 기준 A4 40쪽 이상 (크몽 전자책 구매자의 최소 기대치)

D. 등록·심사 (D-2 ~ D-day)

  • 카테고리 선택: 전자책 > 직무·실무 계열 (정확한 경로는 등록 화면에서 확인)
  • 서비스 제목 입력 (02_서비스문안.md 후보 중 1개)
  • 썸네일 제작 — 텍스트 3줄 이내, 모바일에서 읽히는 크기
  • 상세 설명 붙여넣기 (02_서비스문안.md)
  • 패키지 3종 + 가격 입력
  • FAQ 5개 입력
  • 취소·환불 규정 문구 입력 (디지털 콘텐츠 특성 명시)
  • 제출 → 심사 결과 대기
  • 반려 시: 사유를 이 파일 하단 로그에 기록하고 수정 후 재제출

반려를 부르는 흔한 원인

  1. 상세페이지에 외부 연락처(카카오톡 ID, 이메일, 전화번호, 개인 블로그 링크) 노출
  2. 타 플랫폼 유도 문구
  3. 근거 없는 효과 보장 표현("무조건", "100% 합격", "수익 보장")
  4. 저작권이 불명확한 이미지 사용
  5. 제공 범위가 불명확한 패키지 구성
