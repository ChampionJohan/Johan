# 월 50만원 실행계획

**결론 세 줄**

1. 전자책만으로 월 50만원은 **21건**을 팔아야 한다. 신규 상품이 첫 달에 낼 수 없는 숫자다.
2. 객단가 5만~10만원짜리 **첨삭·상담 서비스**를 주력에 두면 같은 금액이 **13건**으로 줄고, 이건 주 3건이다.
3. 첨삭 서비스는 **원고를 쓸 필요가 없다.** 오늘 등록할 수 있다. 전자책은 그 뒤에 만든다.

기존 계획은 순서가 틀렸다. 원고 8시간을 먼저 쓰고 등록하는 구조였다.
그 8시간 동안 매출은 0원이다. 순서를 뒤집는다.

---

## 1. 왜 전자책 단독으로는 안 되는가

수수료 20%를 가정하면 실수령 50만원에는 정가 **625,000원**이 필요하다.
(정확한 수수료율은 `kmong/01_체크리스트.md` A단계에서 직접 확인해 기입한다)

| 구성 | 정가 | 필요 건수 | 현실성 |
|---|---|---|---|
| 전자책 단독 (29,900원) | 29,900 | **21건** | 리뷰 0건 신규 상품에 불가능 |
| 첨삭 주력 + 전자책 보조 | 혼합 | **13건** | 주 3건. 가능한 범위 |

객단가가 3배면 필요 건수는 3분의 1이다. 이것이 전부다.
크몽에서 신규 판매자가 첫 달에 21건을 파는 경우는 사실상 없다.

## 2. 상품 3종 구조

| # | 상품 | 정가 | 역할 | 준비 시간 |
|---|---|---|---|---|
| A | IT 사업관리 직무 **경력기술서 첨삭** | 49,000 / 99,000 | **주력 매출** | 2시간 (문안만) |
| B | 공공 IT 분야 **이직·커리어 1:1 상담** (40분) | 99,000 | 상한선 | 1시간 (문안만) |
| C | 전자책 「공공 IT 사업관리 실무」 | 19,900 | 리뷰 수집 + 유입 | 8시간 (원고) |

### 50만원 조합 (실수령 기준)

| 상품 | 정가 | 건수 | 소계 |
|---|---|---|---|
| A 첨삭 DELUXE | 99,000 | 4 | 396,000 |
| A 첨삭 STANDARD | 49,000 | 2 | 98,000 |
| C 전자책 | 19,900 | 7 | 139,300 |
| **정가 합계** | | **13건** | **633,300** |
| 수수료 20% 차감 시 실수령 | | | **약 506,600** |

C(전자책)의 진짜 역할은 매출 13만원이 아니다. **19,900원짜리를 산 사람이 99,000원짜리를 산다.**
전자책 구매자가 첨삭 고객이 되는 경로가 이 구조의 핵심이다.

## 3. 왜 "제안서 첨삭"이 아니라 "경력기술서 첨삭"인가

**겸직·이해충돌 때문이다. 이 항목이 이 계획에서 가장 중요하다.**

현재 IT 사업관리 실무자로 재직 중인 상태에서 다음은 하지 않는다.

| 하지 않는다 | 이유 |
|---|---|
| 공공 입찰 제안서 첨삭·대행 | 회사가 참여하는 시장과 직접 경쟁. 이해충돌 |
| 특정 사업의 산출물 작성 대행 | 같은 이유 + NDA 위험 |
| 재직 회사·발주처가 식별되는 사례 공개 | 취업규칙 위반 소지 |

| 해도 되는 영역 | 이유 |
|---|---|
| 직무 경력기술서·이력서 첨삭 | 개인 구직자 대상. 회사 사업과 무관 |
| 커리어 상담 | 같음 |
| 일반화된 실무 지식 전자책 | 공개 지식 + 일반론. 특정 사업 정보 없음 |

**착수 전 반드시 할 일**: 회사 취업규칙의 겸직 조항을 확인한다.
사규에 겸직 신고 의무가 있으면 신고한다. 이 확인 없이 시작하지 않는다.
월 50만원보다 15년 경력이 비싸다.

## 4. 4주 실행 계획

주말·퇴근 후 기준. 총 투입 시간 약 **20시간**.

### 1주차 — 현금이 들어올 창구부터 연다 (5시간)

| 일 | 작업 | 시간 |
|---|---|---|
| 월 | 회사 취업규칙 겸직 조항 확인 | 30분 |
| 화 | 크몽 가입 → 전문가 전환 → 정산계좌 등록 | 40분 |
| 수 | 경쟁 상품 5개 조사 (검색어: `경력기술서`, `이직 첨삭`, `IT 이력서`) | 1시간 |
| 목 | **A 상품(첨삭) 등록** — `kmong/04_첨삭서비스문안.md` 붙여넣기 | 1시간 30분 |
| 금 | 썸네일 제작 (Canva 무료, 텍스트 3줄) | 40분 |
| 토 | **B 상품(상담) 등록** | 40분 |

**1주차 끝 = 판매 창구 2개 오픈.** 이때부터 매출이 발생할 수 있다.

### 2주차 — 첫 리뷰 3건 (4시간)

리뷰 0건 상품은 노출돼도 팔리지 않는다. 임계점은 3건이다.

| 작업 | 방법 |
|---|---|
| 지인·전 동료 3명에게 첨삭 제공 | 정가로 구매 → 실제 첨삭 수행 → 솔직한 후기 요청 |
| 첨삭 작업 표준화 | 1건당 90분을 넘기지 않는 체크리스트 만들기 |

대가를 주고 후기를 사지 않는다. 실제로 서비스를 제공하고 후기를 받는다.
전자는 적발 시 상품이 내려간다.

### 3주차 — 전자책 원고 (8시간)

`kmong/03_전자책원고.md` 의 TODO 11곳을 채운다. 하루 2시간씩 4일.
이미 구조와 본문 골격은 있다. 채우는 것은 **본인 경험뿐**이다.

| 일 | 작업 |
|---|---|
| 월~목 | TODO 채우기 (하루 2~3개) |
| 금 | NDA 경계선 검토 → 발주처·사업명·금액 삭제 |
| 토 | PDF 변환 + 부록 템플릿 4종 제작 |
| 일 | **C 상품(전자책) 등록** |

### 4주차 — 블로그 개설과 첫 글 (3시간)

| 작업 | 시간 |
|---|---|
| 티스토리 개설 + 기본 설정 | 40분 |
| 네이버 서치어드바이저 · 구글 서치콘솔 등록 | 40분 |
| 첫 글 2편 발행 (전자책 1장·4장을 잘라서) | 1시간 40분 |

블로그는 이번 달 수익이 아니다. **6개월 뒤 크몽으로 사람을 보내는 통로**다.
여기서 광고 수익을 기대하지 않는다. 이유는 6절에 있다.

## 5. 블로그 플랫폼 확정: 티스토리

선택 근거 세 가지.

1. **비용 0원**, 애드센스 직접 게재 가능 (네이버 블로그는 불가)
2. **다음 + 구글** 양쪽 검색 유입. 공공 IT 분야 검색자 연령대와 맞는다
3. 공식 API가 종료돼 자동화는 브라우저 조작뿐 → **Playwright 선호와 일치**

대안을 뺀 이유.

| 플랫폼 | 뺀 이유 |
|---|---|
| 워드프레스 + 자체 도메인 | 연 3~6만원 + 세팅 반나절. 6개월 뒤 유입이 확인되면 그때 이전 |
| GitHub Pages | 애드센스 승인에 자체 도메인이 사실상 필요. 검색 유입이 가장 느리다 |
| 네이버 블로그 | 애드센스 불가. 자동 등록은 계정 제재 위험 |

**운영 규칙**: 주 2회 발행. 한 편은 전자책 한 장을 잘라 쓴다.
글 끝에 크몽 상품 링크를 한 줄 넣는다. 이것이 유입 경로다.

## 6. 애드센스로 50만원을 벌 수 없는 이유

한국어 블로그 RPM(1,000회 노출당 수익)은 대체로 1,000~3,000원 구간이다.

| 월 방문 | 광고 수익(추정) |
|---|---|
| 1,000 | 1,000 ~ 3,000원 |
| 5,000 | 5,000 ~ 15,000원 |
| 30,000 | 3만 ~ 9만원 |

월 50만원을 광고로만 채우려면 **월 방문 20만 회 규모**가 필요하다. 6개월로는 불가능하다.

블로그의 실제 수익 경로는 이쪽이다.

```
블로그 월 방문 5,000  →  크몽 상품 클릭 2% (100명)  →  구매 5% (5건)
→  평균 객단가 60,000원  →  월 30만원
```

같은 방문자로 광고는 1만원, 유입은 30만원이다. **30배 차이다.**
그래서 블로그에는 광고를 나중에 붙이고, 상품 링크를 먼저 붙인다.

## 7. 현실적인 월별 예상

과장하지 않은 수치다.

| 시점 | 리뷰 | 예상 실수령 | 근거 |
|---|---|---|---|
| 1개월차 | 0~3건 | **5만 ~ 15만원** | 노출이 거의 없다. 리뷰 쌓는 기간 |
| 2개월차 | 3~6건 | **15만 ~ 30만원** | 리뷰 3건 통과 후 검색 노출 시작 |
| 3개월차 | 6~10건 | **30만 ~ 50만원** | 목표 사정권 진입 |
| 6개월차 | 15건+ | **50만 ~ 80만원** | 블로그 유입 합류 |

**월 50만원은 첫 달 목표가 아니라 3개월차 목표다.**
첫 달 목표는 금액이 아니라 **리뷰 3건**이다. 그것이 다음 달 매출을 만든다.

## 8. 하지 말아야 할 것

| 하지 않는다 | 이유 |
|---|---|
| 상품 5개 동시 등록 | 하나도 리뷰가 안 쌓인다. 2개로 시작한다 |
| 가격 최저가 경쟁 | 19,900원 상품으로 50만원은 25건이다. 객단가를 지킨다 |
| 지인에게 무료 제공 후 후기 요청 | 대가성 후기로 분류될 수 있다. 정가 구매 후 실제 서비스 제공 |
| 블로그 자동 발행부터 만들기 | 팔 상품이 없는데 유입을 만드는 순서는 틀렸다 |
| 재직 회사·발주처가 드러나는 사례 사용 | 금액보다 손실이 크다 |
