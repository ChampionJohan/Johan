# 크몽 전자책 등록 체크리스트

**결론부터**: 전자책 상품 하나를 파는 데 필요한 작업은 크게 4단계, 순수 작업 시간 기준 **12~16시간**이다.
원고가 아니라 **등록 이후의 리뷰 확보**가 매출을 가른다. 아래 순서대로 진행한다.

| 단계 | 기간 | 작업 시간 | 산출물 |
|---|---|---|---|
| A. 계정·정산 준비 | D-14 | 1h | 판매 회원 전환 완료 |
| B. 상품 설계 | D-13 ~ D-10 | 3h | 타깃·가격·패키지 확정 |
| C. 원고·파일 | D-9 ~ D-3 | 8h | PDF 본편 + 부록 템플릿 |
| D. 등록·심사 | D-2 ~ D-day | 2h | 서비스 승인 |
| E. 발행 후 운영 | D+1 ~ D+30 | 주 1h | 리뷰 3건, 문안 개선 |

## A. 계정·정산 준비 (D-14)

- [ ] 크몽 회원가입 → **전문가(판매) 전환** 신청
- [ ] 본인 인증 완료
- [ ] 정산 계좌 등록 (예금주 = 가입자 본인 명의)

## B. 상품 설계 (D-13 ~ D-10)

### B-1. 타깃 한 문장으로 고정

- [ ] 아래 문장을 채운다. 채워지지 않으면 상세페이지도 안 써진다.

```
이 전자책은 ( 누가 )가 ( 어떤 상황 )에서 ( 무엇 )을 ( 얼마 만에 ) 끝내게 해 준다.
```

크몽은 STANDARD / DELUXE / PREMIUM 3패키지 구조를 쓴다. **중간 패키지를 팔기 위해 양옆을 설계한다.**

## D. 등록·심사 (D-2 ~ D-day)

- [ ] 카테고리 선택: 전자책 > 직무·실무 계열 (정확한 경로는 등록 화면에서 확인)
- [ ] 서비스 제목 입력 (`02_서비스문안.md` 후보 중 1개)
- [ ] 썸네일 제작 — 텍스트 3줄 이내, 모바일에서 읽히는 크기
- [ ] 상세 설명 붙여넣기 (`02_서비스문안.md`)
- [ ] 패키지 3종 + 가격 입력
- [ ] FAQ 5개 입력
- [ ] 취소·환불 규정 문구 입력 (디지털 콘텐츠 특성 명시)
- [ ] 제출 → 심사 결과 대기
- [ ] **반려 시**: 사유를 이 파일 하단 로그에 기록하고 수정 후 재제출

### 반려를 부르는 흔한 원인

1. 상세페이지에 **외부 연락처**(카카오톡 ID, 이메일, 전화번호, 개인 블로그 링크) 노출
2. 타 플랫폼 유도 문구
3. 근거 없는 효과 보장 표현("무조건", "100% 합격", "수익 보장")
4. 저작권이 불명확한 이미지 사용
5. 제공 범위가 불명확한 패키지 구성

- [ ] 조회 자체가 없다 → 제목 키워드를 바꾼다 (`사업관리` → `공공 SI 운영 PM` 등 검색어 변형)
