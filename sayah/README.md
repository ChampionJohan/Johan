# SayAh · 아파요

**말이 통하지 않아도 아픈 곳을 전달할 수 있는 오프라인 의료 소통 카드.**
Point and tap to tell a clinician where it hurts — in 10 languages, with no
network and no account.

낯선 나라에서 아플 때, 그리고 한국에서 일하는 외국인 노동자가 병원에 갈 때,
가장 먼저 무너지는 것은 의료 기술이 아니라 **말**입니다. 이 앱은 그 한 칸을
메우기 위한 것입니다.

---

## 이 앱이 하는 일 / 하지 않는 일

| 합니다 | 하지 않습니다 |
|---|---|
| 아픈 부위·증상·통증 정도를 **상대 언어로 번역해 보여줌** | 진단 |
| 알레르기·복용약·혈액형을 미리 저장해 한 장으로 제시 | 치료·투약 조언 |
| 의사가 자주 묻는 말을 **내 언어로** 보여주는 양방향 대화 | 중증도 판단(triage) |
| 나라별 응급 전화번호 안내 | 병원 예약·보험 청구 |

앱 안에도 모든 언어로 같은 문구가 항상 표시됩니다:
> 이 앱은 의사소통을 돕는 도구입니다. 진단이나 치료 조언을 하지 않습니다.
> 응급 상황에서는 반드시 응급 번호로 전화하세요.

---

## 설계 원칙 3가지

**1. 완전 오프라인.**
로밍이 끊긴 공항, 데이터가 없는 시골 병원에서 쓰이는 앱입니다. 외부 요청이
**하나도 없고**, 모든 번역이 파일 안에 들어 있습니다. 서비스 워커가 앱 전체를
캐시하므로 비행기 모드에서도 그대로 동작합니다. (검증 결과는 아래 참조)

**2. 아무것도 밖으로 나가지 않음.**
알레르기·지병 같은 민감한 건강 정보는 `localStorage`에만 저장되고 서버로
전송되지 않습니다. 계정도, 분석 도구도, 외부 스크립트도 없습니다. 미등록
체류자처럼 기록이 남는 것 자체가 위험한 사람도 쓸 수 있어야 하기 때문입니다.

**3. 일상어만 사용.**
의학 전문용어 대신 "숨쉬기 힘들어요", "토할 것 같아요" 같은 생활 표현만
씁니다. 번역 오류 위험이 줄고, 환자 본인이 단어를 알아볼 수 있습니다.

## 지원 언어 (10개)

한국어 · English · 中文 · 日本語 · Tiếng Việt · ไทย · Bahasa Indonesia ·
Filipino · Español · Русский

한국 체류 외국인 주요 언어와 한국인 여행 목적지를 함께 고려해 선정했습니다.

> ⚠️ **실제 배포 전 반드시 필요한 작업**: 127개 문구 × 10개 언어의 번역은
> 자동 검증(모든 문구가 10개 언어를 빠짐없이 가짐)까지만 되어 있고, **원어민
> 검수는 아직 거치지 않았습니다.** 의료 현장에 쓰기 전에 언어별 원어민(가능하면
> 의료 통역사) 검수를 거쳐야 합니다. 번역 데이터는 `index.html`의 `T("…")`
> 한 줄에 10개 언어가 나란히 들어 있어 검수자가 바로 비교·수정할 수 있습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 🧍 어디가 | 인체 그림(앞/뒤) 터치 + 눈·귀·코·입 세부 선택 |
| 🤒 증상 | 20개 증상 카드, 통증 0~10 슬라이더, 발생 시점 |
| 💬 대화 | 급할 때 하는 말 8개 · 의사가 묻는 말 11개 · 빠른 대답 6개 |
| 🪪 내 정보 | 알레르기·복용약·지병·혈액형·나이·임신 여부 (기기에만 저장) |
| 🚨 응급번호 | 15개 국가/지역 구급차·경찰 번호 (`tel:` 바로 걸기) |

하단 **"의사에게 보여주기"** 버튼을 누르면 상대 언어 큰 글씨 + 내 언어 대조
표기가 함께 담긴 요약 카드가 나옵니다. 양쪽 언어를 동시에 보여주기 때문에
주변에 이중언어 사용자가 있으면 오역을 즉시 잡아낼 수 있습니다.

### 좌/우 표기 주의
앞모습은 **나를 마주 본 그림**이므로 화면 왼쪽이 환자의 오른쪽입니다.
뒷모습은 좌우가 그대로입니다. 앱이 그림 위에 "오른쪽/왼쪽"을 직접 표시하고,
내부 데이터도 그에 맞춰 좌우를 뒤집습니다. (이 동작은 테스트로 고정되어 있습니다)

## 검증 결과

헤드리스 Chromium + DevTools Protocol로 실제 브라우저에서 확인했습니다.

```
기능 테스트           PASS 50 / FAIL 0
오프라인 테스트        캐시 8개 파일 → 네트워크 차단 상태에서 앱 전체 정상 동작
번역 커버리지          T() 127개 전부 10개 언어 채워짐 (빈 칸 0)
외부 요청 수           0
런타임 예외            0
```

테스트가 실제로 잡아낸 결함 하나: 인체 그림 부위에 `role="button" tabindex="0"`만
주고 키보드 활성화를 연결하지 않아, 키보드·스위치 사용자가 부위를 선택할 수
없었습니다. Enter/Space 처리를 추가하고 테스트로 고정했습니다.

## 실행 방법

정적 파일이라 서버가 필요 없지만, 서비스 워커(오프라인 캐시)는 `file://`에서
동작하지 않으므로 간단한 서버로 열어야 합니다.

```bash
cd sayah
python3 -m http.server 8801
# 브라우저에서 http://localhost:8801
```

휴대폰 홈 화면에 추가하면 PWA로 설치되어 오프라인에서 앱처럼 실행됩니다.
iOS 네이티브 앱으로 감싸려면 `../mobile`의 Capacitor 설정과 같은 방식을
쓰면 됩니다 (`webDir`만 이 폴더로 변경).
