# 얼마나와 — 전기요금 누진세 계산기

**이번 달 전기요금이 얼마 나올지, 그리고 지금 1kWh 더 쓰면 얼마가 더 붙는지.**

누진제의 진짜 함정은 단가가 오르는 게 아니라 **기본요금이 계단처럼 뛴다**는 점입니다.
기타계절 기준 400kWh에서 401kWh로 넘어가는 순간 기본요금이 1,600원 → 7,300원으로
바뀌어서, 그 **1kWh의 실제 비용이 6,840원**이 됩니다. 평소 1kWh가 214원인데 말이죠.

이걸 암산으로 아는 사람은 없고, 알려주는 앱도 없었습니다. 이 앱이 하는 일이 그겁니다.

---

## 핵심 기능 4가지

| 기능 | 설명 |
|---|---|
| **예상 청구금액** | 사용량만 넣으면 기본요금·전력량요금·기후환경요금·연료비조정액·부가세·기금까지 고지서 그대로 계산 |
| **누진 절벽 경고** | 다음 단계까지 몇 kWh 남았는지, 그 선을 넘는 1kWh에 얼마가 붙는지 |
| **가전 시뮬레이터** | "에어컨 3시간씩 10일 더 쓰면?" → 추가 금액 + 단계 상승 여부 |
| **검침일 예측** | 지금까지 쓴 양 + 지난 일수 → 월말 예상 사용량과 요금 |

가전 시뮬레이터의 추가 금액은 단가 곱셈이 아니라 **`전체요금(지금+추가) − 전체요금(지금)`**
으로 계산합니다. 그래야 구간을 넘어가는 경우까지 정확합니다. 단순 곱셈으로 하면
절벽을 넘는 상황에서 금액을 크게 과소평가하게 됩니다.

## 적용 요금표

**주택용 저압** (단독주택·다세대)

| 단계 | 기타계절(1~6월, 9~12월) | 하계(7~8월) | 기본요금 | 전력량요금 |
|---|---|---|---|---|
| 1단계 | 0~200kWh | 0~300kWh | 910원 | 120.0원/kWh |
| 2단계 | 201~400kWh | 301~450kWh | 1,600원 | 214.6원/kWh |
| 3단계 | 400kWh 초과 | 450kWh 초과 | 7,300원 | 307.3원/kWh |

**주택용 고압** (대부분의 아파트)

| 단계 | 기본요금 | 전력량요금 |
|---|---|---|
| 1단계 | 730원 | 105.0원/kWh |
| 2단계 | 1,260원 | 174.0원/kWh |
| 3단계 | 6,060원 | 242.3원/kWh |

**공통**: 기후환경요금 9.0원/kWh, 연료비조정액 +5.0원/kWh, 부가가치세 10%,
전력산업기반기금 3.7%

**계산식**
```
전기요금계 = 기본요금 + 전력량요금 + 기후환경요금 + 연료비조정액
청구금액   = 전기요금계 + 부가세(10%) + 전력산업기반기금(3.7%)
```
전력량요금·기후환경요금·연료비조정액은 원 미만 절사, 기금은 10원 미만 절사,
청구액은 10원 미만 절사.

> ⚠️ **반영하지 않은 것**: 복지할인, 다자녀·대가족 할인, 에너지캐시백 등 개별 할인.
> 해당되시면 실제 고지서는 이보다 적게 나옵니다.
>
> 연료비조정액은 분기마다 바뀝니다(2026년 4분기 기준 +5원, 11분기 연속 동결).
> 요금표가 개정되면 `index.html`의 `TARIFF` / `CLIMATE` / `FUEL` 상수만 고치면 됩니다.

## 검증 결과

요금 계산은 **UI를 만들기 전에** 손으로 계산한 값과 먼저 대조했고, 그다음 실제
브라우저에서 다시 확인했습니다.

```
기능 테스트        PASS 37 / FAIL 0
오프라인 테스트     캐시 8개 파일 → 네트워크 차단 상태에서 계산까지 정상
외부 요청 / 예외    0 / 0
```

대조한 기준값 (저압·기타계절):

| 사용량 | 손계산 | 앱 |
|---|---|---|
| 300kWh | 58,270원 | ✅ |
| 350kWh | 71,260원 | ✅ |
| 400kWh | 84,270원 | ✅ |
| 401kWh | 91,110원 | ✅ |

구조 점검도 함께 넣었습니다: 0~1,200kWh 전 구간에서 사용량이 늘면 요금도 반드시
늘어날 것, 고압이 저압보다 쌀 것, 하계 구간완화가 더 쌀 것, 내역 합계가 청구액과
일치할 것 — 요금표를 수정하다 식을 깨뜨리면 바로 걸립니다.

테스트가 잡아낸 결함 하나: 누진 게이지에서 현재 위치 표시(▲390)와 구간 경계
라벨(400)이 같은 줄에 겹쳐 글자가 깨졌습니다. 사용량이 경계 근처일 때 — 즉 사람들이
가장 주의 깊게 보는 바로 그 순간 — 발생해서, 두 줄로 분리했습니다.

## 실행 방법

```bash
cd power-bill
python3 -m http.server 8802
# 브라우저에서 http://localhost:8802
```

휴대폰 홈 화면에 추가하면 PWA로 설치되어 오프라인에서 앱처럼 실행됩니다.

입력값은 전부 `localStorage`에만 저장되고 외부로 전송되지 않습니다. 네트워크 요청이
하나도 없어서 서버 비용 없이 영구히 운영 가능합니다.
