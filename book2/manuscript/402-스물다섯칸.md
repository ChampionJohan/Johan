## 창의는 떠오르는 것이 아니다

새 사업 아이디어를 어떻게 얻느냐고 물으면 대개 이런 답이 돌아온다.
평소에 문제의식을 갖고 있어라, 불편한 것을 메모해라, 많이 읽어라.

**틀린 말은 아닌데 실행할 수가 없다.** 언제 떠오를지 알 수 없기 때문이다.

이 장은 다른 방식을 쓴다.

> **떠오르기를 기다리지 않고, 경우의 수를 전부 적어 놓고 고른다.**

이 책에는 이미 재료가 다 있다. 1부의 **해자 다섯 유형**과
14장에서 뒤집은 **입구 다섯 개**다.

다섯에 다섯을 곱하면 스물다섯이다.
**스물다섯 개의 질문이 자동으로 생긴다.**

## 흔한 오해 — 좋은 아이디어 하나면 된다

아이디어 하나를 잘 골라야 한다고들 생각한다.

**절반만 맞다.**

결국 하나를 고르는 것은 맞다. 그런데 **하나만 놓고 고르면 고른 것이 아니다.**
비교 대상이 없으면 그게 좋은지 나쁜지 판단할 근거가 없다.

그리고 처음 떠오른 아이디어는 대개 **가장 익숙한 것**이지 가장 좋은 것이 아니다.
남들도 똑같이 떠올린다.

> **하나를 오래 다듬는 것보다, 스물다섯 개를 훑고 셋을 남기는 편이 낫다.**

## 격자를 그린다

세로에 1부의 다섯 유형, 가로에 14장의 다섯 입구를 놓는다.

| | 규제가 바뀜 | 기술이 대체 | 고객이 이동 | 공급자 분산 | 큰 쪽이 못 함 |
|---|---|---|---|---|---|
| **규모의 경제** | | | | | |
| **네트워크 효과** | | | | | |
| **전환 비용** | | | | | |
| **무형자산** | | | | | |
| **원가 우위** | | | | | |

각 칸에 넣는 질문은 항상 같은 문장이다.

> **"○○ 때문에 열린 자리에 △△ 해자를 심으면 어떤 사업이 되는가?"**

예를 들어 **[전환 비용 × 규제가 바뀜]** 칸은 이렇게 읽는다.

> 새 규정을 지켜야 하는 사람들의 기록이 내 쪽에 쌓이게 하면,
> 규정을 다 지킨 다음에도 그 기록 때문에 못 옮기지 않을까?

**[무형자산 × 공급자 분산]** 칸은 이렇게 읽는다.

> 흩어진 생산자를 묶어 주면서, 묶어 주는 쪽의 이름이 품질의 보증이 되면
> 시간이 갈수록 다른 사람이 대신 묶기 어려워지지 않을까?

칸마다 이렇게 한 문장씩 나온다. **떠오르기를 기다린 것이 아니라 자리에서 나온 것이다.**

## 빈 칸이 알려 주는 것

격자를 채우다 보면 **잘 안 채워지는 칸**이 나온다. 그게 정보다.

세로줄부터 보자.

**규모의 경제와 원가 우위 줄은 대개 잘 안 채워진다.**
자본이 필요하기 때문이다. 닫는 글에서 다룰 이야기가 여기서 미리 보인다.

**전환 비용과 무형자산 줄은 대부분의 칸이 채워진다.**
이 두 해자는 심는 데 돈이 아니라 시간과 설계가 들기 때문이다.

가로줄도 보자.

**「큰 쪽이 못 하는 일」 열은 거의 모든 칸이 채워진다.**
큰 회사가 구조상 못 하는 일은 어느 업계에나 있기 때문이다.

**「규제가 바뀜」 열은 아는 업계에서만 채워진다.**
바깥에서 보면 규정이 언제 어떻게 바뀌는지 안 보인다.

> **격자가 안 채워지는 것은 상상력이 부족해서가 아니라
> 그 조합이 자기 조건에 안 맞기 때문이다.**

## 셋으로 줄이는 법

스물다섯 칸을 다 채웠으면 이제 줄인다. 세 가지 질문으로 거른다.

**하나. 이 자리가 왜 지금 비었는지 한 문장으로 쓸 수 있는가?**

못 쓰면 뺀다. 14장에서 말한 그대로다.
"아무도 생각 못 해서"는 이유가 아니다.

**둘. 첫 고객 열 명을 어디서 만날지 지금 말할 수 있는가?**

못 말하면 뺀다. 이건 냉정한 기준인데, 첫째 권 1장의 질문이 여기서 돌아온다.
**진짜로 돈을 내는 사람이 누구인가.** 그 사람을 어디서 만나는지 모르면
아직 첫째 칸이 안 채워진 것이다.

**셋. 이 일을 하면서 무엇이 쌓이는가?**

아무것도 안 쌓이면 뺀다. 열심히 해도 다음 달에 처음부터 다시 시작하는 일이면
해자가 절대 안 생긴다. 16장의 주제다.

세 질문을 통과하는 칸은 대개 스물다섯 중 두세 개다. **그 정도면 충분하다.**

## 조합을 비트는 세 가지 방법

격자를 채워도 평범한 답만 나올 때가 있다. 그때 쓰는 방법이 셋 있다.

**하나, 겹친다.**

한 칸이 아니라 두 칸을 동시에 쓴다.
4장에서 무형자산이 여러 겹으로 되어 있는 것을 봤다.
겹치면 따라 하기가 훨씬 어려워진다.

> 한 겹은 따라 하기 쉽다. **세 겹은 셋을 다 따라 해야 한다.**

다만 겹마다 수명이 다르다는 것도 4장에서 봤다.
**제도로 만든 겹은 제도가 바뀌면 사라지고, 시간으로 쌓은 겹은 안 사라진다.**

**둘, 뒤집는다.**

약점처럼 보이는 것을 조건으로 바꾼다.

작아서 못 하는 것이 많다. 그런데 10장에서 봤듯이
**작아야만 할 수 있는 일**도 그만큼 있다.
느려서 못 하는 것이 있고, 느려야 되는 것도 있다.

> **"우리는 ○○가 없어서 못 한다"를 "○○가 없어서 할 수 있다"로 바꿔 써 본다.**

바꿔 써서 말이 되면 그게 자리다. 말이 안 되면 그냥 약점이 맞다.

**셋, 좁힌다.**

가장 확실한 방법이고 가장 안 쓰는 방법이다.

같은 아이디어를 **한 지역, 한 직군, 한 상황**으로 좁힌다.
좁히면 시장이 작아진다. 그런데 좁히면 세 가지가 동시에 좋아진다.

- 첫 고객을 어디서 만날지가 분명해진다
- 큰 회사가 안 들어온다. **작아서 수지가 안 맞기 때문이다**
- 그 좁은 곳에서 이름이 쌓인다. 무형자산이 빨리 붙는다

**넓게 시작해서 좁히는 것보다 좁게 시작해서 넓히는 편이 훨씬 쉽다.**
좁은 곳에서 쌓은 이름은 옆으로 옮겨 가지만, 넓은 곳에서 안 쌓인 이름은 옮길 것이 없다.

## 이 방법의 한계

정직하게 적어 둔다. **격자는 아이디어를 만들어 주지 결과를 보장하지 않는다.**

13장에서 이 책이 못 보는 것을 이미 밝혔다.
실행의 질, 사람, 타이밍, 운. 격자는 그중 어느 것도 안 알려 준다.

그러니 격자의 역할은 하나다.

> **고를 것이 하나뿐인 상태에서 벗어나게 해 준다.**

하나뿐이면 고른 것이 아니라 떠맡은 것이다.

## 정리

- 창의를 기다리지 말고 **다섯 유형 × 다섯 입구 = 스물다섯 칸**을 적어 놓고 고른다.
- 각 칸의 질문은 늘 같다. **"이 입구에 이 해자를 심으면 무슨 사업이 되는가?"**
- **안 채워지는 칸도 정보다.** 자본이 필요한 두 줄은 원래 잘 안 채워진다.
- 세 질문으로 거른다. **왜 비었나 · 첫 고객 열 명을 어디서 만나나 · 무엇이 쌓이나.**
- 평범할 때는 **겹치고, 뒤집고, 좁힌다.** 셋 중 좁히기가 가장 확실하다.

## 직접 해 보기

격자를 그린다. 스물다섯 칸을 다 채우려 하지 말고,
**자기가 아는 업계에서 채워지는 칸만** 채운다.

다섯 칸쯤 채워졌으면 세 질문으로 거른다.

> 1. 이 자리가 왜 지금 비었는가? ______
> 2. 첫 고객 열 명을 어디서 만나는가? ______
> 3. 이 일을 하면 무엇이 쌓이는가? ______

살아남은 칸에 **좁히기**를 한 번 적용해 본다.

> 이것을 ______ 에게만 판다면?

빈칸에 지역이든 직군이든 상황이든 하나를 넣어 본다.
**넣었을 때 첫 고객 열 명의 얼굴이 떠오르면 제대로 좁힌 것이다.**
